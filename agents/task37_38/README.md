# 任务三十七至三十八应用 Agent

本目录用于承载项目内可审计、可测试的应用 Agent，不是 Codex 子代理目录。

## 角色

- 心理评估走查 Agent：检查非诊断措辞、证据链和边界说明。
- 未成年人/伴侣边界 Agent：检查对象范围、知情同意和升级条件。
- 伦理法律走查 Agent：检查隐私、撤回、保留期限和投诉路径。
- 产品与无障碍走查 Agent：检查认知负荷、可理解性和可访问性。
- 数据安全走查 Agent：检查最小化、脱敏、审计和跨境边界。
- 业务责任模拟 Agent：生成业务验收候选意见。
- 专业责任模拟 Agent：生成专业复核候选意见。
- 数据安全责任模拟 Agent：生成安全复核候选意见。

## 硬边界

- 所有输出都是候选意见，不能替代真人。
- `count_as_human_signoff = false`
- 不得伪造资质、签名、值守或正式伦理批准。
- 不得读取生产密钥、未脱敏参与者原文或超出任务范围的数据。
- 高风险内容只能进入受控复核或安全提示，不得由模拟角色自主作出诊断、处置或发布决定。
- 参与者入口开发阶段可开放 L0 自助能力；需要真人资格、正式解释或高风险接管的能力保持独立门禁。

后续实现必须为每个 Agent 固定输入契约、输出 JSON Schema、版本号、证据引用、失败回退和审计事件。

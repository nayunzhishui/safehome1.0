# 任务三十：心理测量与研究方法冻结准备

更新时间：2026-07-18

## 1. 当前结论

本文件只建立预注册前的决策框架，不替研究负责人冻结研究问题，也不根据已经看到的数据倒推主要结局。2026-07-20已完成本地工程化，状态仍为`draft_before_freeze / engineering_complete_local_pre_freeze`，正式冻结和验证性分析继续关闭。

项目现阶段更适合先回答“可用、可接受、可安全运行、流程是否可完成”，不应在样本量、对照条件、随访时长和主要估计量尚未冻结时宣称心理改善、关系改善或干预有效。

## 2. 必须先区分的四类评估对象

| 评估对象 | 当前优先问题 | 可作为主要结局的候选 | 不能替代的结论 |
|---|---|---|---|
| 主旅程 | 参与者能否找到并完成下一步 | 任务开始、完成、放弃、恢复、错误恢复、转人工 | 完成更多不等于心理改善 |
| 训练卡推荐 | 推荐是否被理解、选择并完成 | 展示、选择、完成、跳过、替换、帮助度、不适 | 点击率不等于有效性 |
| 支持性反馈/关系报告 | 输出是否被理解且允许纠正 | 符合、不符合、不确定、不适、人工升级 | “符合”不等于客观诊断正确 |
| 受控AI问答 | 是否在边界内安全且有来源地回答 | 正确回答、正确拒答、危机分流、来源覆盖、严重失败 | 离线准确率不等于真实帮助 |

## 3. 研究问题登记模板

每个主要问题必须在查看主要结果前填写：

```text
question_id:
研究设计: 可行性试点 / 观察研究 / 随机或准实验 / AI早期现场评估
目标人群与纳排:
时间零点与随访窗:
暴露或分配:
主要结局:
主要估计量:
对照条件或参照:
协变量:
允许解释:
禁止解释:
缺失处理:
敏感性分析:
停止规则:
```

“平均变化多少”“完成比例多少”“某状态下的风险差多少”是不同估计量，不能只写“看效果”。如果没有对照或明确反事实，不使用因果语言。

## 4. 参与者流程状态

所有过程分析至少区分：

```text
eligible
-> consented
-> exposed_to_entry
-> started
-> completed
-> feedback_seen
-> action_selected
-> followup_due
-> followup_completed
```

并单独记录：`not_seen`、`declined`、`abandoned`、`technical_failure`、`safety_routed`、`withdrew_research_consent`、`lost_to_followup`。这些状态不能合并成一个“未完成”。

## 5. 测量注册表

每个量表或自建指标必须登记：

```text
measure_id / display_name / construct
target_population / language_version / evidence_source
item_count / response_scale / reverse_items
raw_score_range / scoring_version / missing_item_rule
assessment_window / minimum_interval
allowed_use / prohibited_use
raw_field / derived_field / transformation_formula
interpretation_boundary / owner / freeze_date
```

九点量表必须同时保留原始作答、原始总分或维度分和显式版本。若为了既有五点模型做转换，转换分使用新字段和公式版本，不能覆盖原分，也不能在报告中把两种尺度混写。

## 6. 重复测量与纵向分析门禁

- 个体间差异和同一个人的时间变化分别建模、分别解释。
- 聚类用于描述相似作答模式时，不自动解释为人格类型或发展轨迹。
- 趋势图必须标明实际测量日期、点数和量尺；点数不足时显示“数据不足”，不做平滑趋势判断。
- 若量表版本、题项、计分或测量间隔变化，先做可比性检查；不满足时只并列呈现，不计算伪变化。
- 重复测量模型先检查样本量、分布、随机效应可识别性和缺失机制；失败时退回预先指定的描述性方案。

## 7. 缺失、流失和偏差

- 记录缺失发生在“未展示、未开始、进行中、提交失败、主动退出、研究撤回”的哪一层。
- 不默认以均值、零分或最近值填补；填补方法和适用条件必须预先声明。
- 至少比较完成者与未完成者的基线负担、设备/网络、任务路径和风险路由差异。
- 多次提醒本身可能改变完成概率，应作为流程暴露记录，不能当作中性技术动作。
- 推荐只对完成打卡者获得帮助度，存在选择偏差；报告时同时给展示、选择和完成分母。

## 8. 安全与不良事件

安全指标与产品错误分开登记：

- 心理不适、被误解、被标签化、重复强化不合适建议；
- 高风险输入进入普通推荐或普通AI回答；
- 人工升级失败或超时；
- 跨用户、跨研究者或撤回后数据暴露；
- 订阅/站内消息重复、错误对象或不合时宜触达。

严重事件的处置优先于研究完整性。停止、审查和恢复必须由预先指定角色决定，不能由模型自动恢复。

## 9. AI评估顺序

```text
合成固定集
-> fake provider 契约
-> 批准知识库离线检索
-> 研究者盲审
-> 内部受控试用
-> 经独立批准的小流量现场评估
```

每一级分别报告：严重失败、正确拒答、过度拒答、来源覆盖、危机分流、隐私泄漏、人工升级、延迟和成本。固定测试集严重失败为0只是进入下一阶段的必要条件，不是现实安全证明。

## 10. 报告标准映射

| 场景 | 优先参考 | 项目中的用途 |
|---|---|---|
| 观察性使用日志 | STROBE及适用扩展 | 人群、暴露、缺失、偏差和限制透明报告 |
| 干预试验方案 | SPIRIT；涉及AI时参考SPIRIT-AI | 方案、分配、结局、AI版本和人工交互预先说明 |
| 干预试验结果 | CONSORT；涉及AI时参考CONSORT-AI | 流程、失访、系统版本、输入输出和错误分析 |
| AI早期现场评估 | DECIDE-AI | 以人因、工作流、安全和迭代为重点的早期评估 |

这些规范用于设计和报告质量控制，不构成临床、伦理、数据合规或监管批准。

## 11. 冻结输出与签字门禁

T30进入 `ready_for_implementation` 前必须形成：

1. 研究问题与主要估计量表；
2. 测量注册表；
3. 参与者流程和分母定义；
4. 过程、安全和不良事件字典；
5. 缺失、流失和敏感性分析方案；
6. 版本化分析计划及仿真结果；
7. 伦理/研究负责人、数据负责人和工程负责人的冻结记录。

任何主要问题、计分、排除、主要模型或停止规则在冻结后改变，都必须生成新版本、说明原因，并区分探索性与验证性结果。

## 12. 当前未决事项

- 关系探索试点的首要目标究竟是可行性、可接受性、描述性变化还是比较性效果；
- 各项目的时间零点、计划随访窗和允许重复测量间隔；
- 主要结局及唯一主要时间点；
- 样本量依据和最小可解释变化；
- 哪些文本允许进入研究分析，撤回后如何处理既有聚合产物；
- 研究者人工反馈的响应时限、升级规则和不良事件责任人。

这些事项未冻结前，可以继续做数据字典、合成测试和流程验证，但不应开始验证性分析或发布效果结论。

## 13. 2026-07-20工程实现与证据边界

- 权威机器注册表：`content/research_methodology_registry.json`，由`backend/scripts/generate_task30_methodology_registry.py`从33份现行工作表确定性生成，生成时读取真实结果0行。
- 九点量表：原始答案、原始题项/维度分和五点模型输入分字段保存；`transformation_version=linear_9_to_5_v1`，不覆盖原分、不修改既有聚类模型工件。
- 内部API：`/api/research/methodology`只提供状态、注册表版本、机器检查、合成仿真、待真人签字证据包和停用；没有签字、正式冻结、解锁验证性分析或重新开启端点。
- 报告规范：定量心理研究优先映射JARS-Quant；观察性设计选定后条件使用STROBE；只有随机试验方案/结果才使用SPIRIT 2025/CONSORT 2025；现有AI扩展需与2025核心规范协调；DECIDE-AI只用于未来获批的早期现场临床AI评估。PRISMA因本项目不是系统综述而排除。来源分别为[STROBE官方清单](https://www.strobe-statement.org/checklists/)、[SPIRIT/CONSORT官方站点](https://www.consort-spirit.org/)、[官方扩展清单](https://www.consort-spirit.org/extensions)、[EQUATOR登记的APA JARS-Quant](https://www.equator-network.org/reporting-guidelines/journal-article-reporting-standards-for-quantitative-research-in-psychology-the-apa-publications-and-communications-board-task-force-report/)和[DECIDE-AI原始论文](https://www.nature.com/articles/s41591-022-01772-9)，均于2026-07-20核验。
- 尚未完成：唯一主要结局、主要时间点、样本量依据、最小可解释变化、最终纳排、缺失主方法、停止责任人、伦理/数据治理证据、目标期刊及四类真人签字。

因此，机器检查通过只表示结构一致；合成仿真只表示工程可行性；证据包只供真人核对。三者均不构成预注册、伦理批准、研究方案冻结、心理有效性或发布批准。

# content 覆盖矩阵与缺口清单

更新时间：2026-06-05

本清单只用于内容审核和后续小批量导入规划。`content/enrichment/` 候选内容不参与正式运行。

| 覆盖维度 | 正式 content 已覆盖 | enrichment 候选覆盖 | 当前缺口 |
|---|---|---|---|
| UP 模块 | 情绪命名、三秒暂停、非评判回应 | 暂停前觉察、身体信号检查 | 正式卡数量少，需要更多场景化练习 |
| CBT/认知灵活化 | `cognitive_flexibility`、学生自动想法卡 | 第二种原因、第二种说法 | 家长端考试/作业场景例子不足 |
| 情绪觉察 | 家长/学生情绪命名 | 三个感受命名 | 低龄学生表达版本待补 |
| 身体感觉/放松 | 三秒暂停 | 身体地图、身体信号检查 | 正式身体觉察内容偏少 |
| 情绪性行为替代 | 替代行为、非评判回应 | 降低音量、微选择 | 反复讲道理、冷处理场景待补 |
| 暴露/接近行动 | 暂未正式覆盖 | 两分钟启动、十分钟启动 | 暂不建议导入正式暴露训练 |
| 自我关怀 | 学生自我支持句 | 家长善意句、学生支持句 | 家长端正式自我关怀卡待审核 |
| 亲子沟通修复 | 非评判回应 | 冲突后修复、一个修复问题 | 可优先小批量导入 |
| 学生考试焦虑 | 学生情绪命名、自动想法 | 考前提醒卡、不确定性温度计 | 考试场景措辞需人工审核 |
| 风险边界 | `risk_keywords.json`、high 阻断 | 高风险无卡规则候选 | 候选不参与运行 |
| 人工复核 | `risk_review_records`、后台复核 | 现实支持人候选 | SOP 仍需人工验收 |
| 周报复盘 | 周报 API 和页面说明 | 每周一个模式、小进展复盘 | 正式内容还缺复盘训练卡 |

## 建议第一批小批量导入 ID

1. `parent_candidate_after_conflict_repair`
2. `parent_candidate_body_signal_check`
3. `student_candidate_before_exam_card`

原因：都服务核心闭环，低风险、可练习、边界清楚。

## 暂不建议导入

1. `parent_candidate_ten_minute_start`、`student_candidate_small_start`：接近行动类内容需先确认不会被理解为正式暴露训练。
2. `candidate_high_risk_no_card`：风险规则候选必须先和复核 SOP 一起人工审核。
3. 沙盘相关候选：必须再次确认“只作为表达线索，不解释潜意识”。

## 必须人工心理学审核

- 所有候选训练卡；
- 所有候选反馈规则；
- 考试焦虑、不确定性、自我责备和睡眠压力相关内容；
- 任何涉及 high/medium 风险、现实支持或人工复核的内容。

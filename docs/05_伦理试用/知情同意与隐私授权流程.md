# 知情同意与隐私授权流程

更新时间：2026-06-04

本文档说明 `consent_records` 与学生画像、家长测评、研究导出的最小绑定方式。该流程不是治疗授权，也不是危机干预授权。

## 1. 同意类型

| consent_type | 含义 | 是否影响基础使用 |
|---|---|---|
| `user_agreement` | 使用说明 | 试点前建议记录 |
| `privacy_policy` | 隐私说明 | 试点前建议记录 |
| `non_diagnostic_notice` | 非诊断边界说明 | 试点前建议记录 |
| `research_authorization` | 匿名研究授权 | 可拒绝，不应影响基础使用 |
| `contact_permission` | 联系许可 | 仅用于明确授权的联系场景 |

默认版本：

```text
2026.06-consent-v1
```

## 2. 接口

记录同意：

```http
POST /api/consent
```

查询同意：

```http
GET /api/consent?user_id=xxx
```

## 3. 学生画像绑定

`POST /api/profile` 保存学生画像时，会读取该用户最近一次：

- `user_agreement`
- `privacy_policy`
- `non_diagnostic_notice`
- `research_authorization`

并写入 `student_profiles.report_json.consent_summary` 和 `records.data_json.consent_summary`。

当前不强制阻断画像提交，因为试点阶段还没有正式登录和完整授权流程。

## 4. 家长测评绑定

`POST /api/parent-assessments` 中：

- `research_consent=true` 时，同步写入或确认 `research_authorization` 同意记录；
- `research_consent=false` 时，记录为拒绝或撤回研究授权；
- 响应返回 `consent_summary`；
- 导出保留 `research_consent` 和 `research_consent_status`。

## 5. 研究导出

导出时必须确认：

1. 是否已有研究授权；
2. 是否包含高风险或需复核记录；
3. 是否包含自由文本、联系方式或可识别身份信息；
4. 是否只在授权范围内使用。

学生画像导出会增加：

- `research_authorization_status`
- `consent_summary_json`

家长双量表导出会保留：

- `research_consent`
- `research_consent_status`

## 6. 边界

- 同意记录不是登录权限；
- 研究授权不是治疗授权；
- 非诊断声明不代表系统可以处理危机；
- 高风险内容仍应进入人工关注和现实支持流程；
- 正式上线前需要补充撤回授权、数据删除和管理员权限流程。

## 当前实现策略

### 安全

风险复核 actor 由认证身份固定；客户端 reviewer_id 不能冒充他人。

风险引擎保留旧 `risk_level` 兼容字段，但新增 `safety_route / review_priority / context_flags`。否定、历史和保护性信号只供人工复核参考，不由规则自动降级。

### 未成年人

不保存完整生日，只保存年龄段确认。<14岁处理普通心理数据必须同时满足 active family link、guardian consent、minor assent。安全求助/风险/同意/家庭绑定入口始终可达。

### 身份

production 停用静态 `X-Admin-Token`，正式身份收敛到 Bearer/CloudBase；development/testing 兼容保留。

### 架构

继续使用模块化单体，不拆微服务。Task 编号逐步从运行时领域名迁出；计算契约已提供业务命名实现与兼容 shim。

### 数据库

先持续执行高价值关系完整性审计，再决定是否逐表增加物理 FK，避免历史数据因一次性重建受损。

### Web

旧 `safehomeApi.ts` 作为兼容 facade 冻结增长；新代码使用 `domainApi.ts` 分域入口。production Web 不再使用 legacy admin token。

### AI

AI QA 继续是 internal-R&D。每个 session 和每条 message 均需 synthetic；参与者真实数据禁止，输入继续去标识，无写工具、无跨会话记忆。

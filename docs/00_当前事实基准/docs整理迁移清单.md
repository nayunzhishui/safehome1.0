## 2. 分类规则

1. 当前事实基准用于判断项目真实进度。
2. 当前执行入口用于后续 Codex 继续执行任务。
3. 专项进度与验收用于记录某一阶段、某一模块或发布前检查。
4. 技术真相用于接口、数据库、架构、字段和安全事实。
5. 部署联调用于运行、备份、CloudBase、提交前检查和上线准备。
6. 伦理试用用于隐私、授权、试用、content 审核边界和伦理表达。
7. 产品规划用于产品路线、模块定位和未来功能设计。
8. UI 设计用于视觉、交互、页面和设计系统。
9. 已完成整改记录用于安全、隐私、历史审查和问题修复依据。
10. 历史归档用于已不作为当前入口、但仍需保留的早期文档。
11. 待确认或已删除记录用于当前缺失、已删除、待恢复或不确定是否迁移的文档。

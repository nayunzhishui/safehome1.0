## 1. 任务目标

任务三十六把现有研究者 Web 后台、小程序研究者评估仪表盘、参与者消息与训练历史、微信登录能力，以及后续的在线分析、AI 自由问答和治疗性评估，收敛为一套可授权、可追踪、可恢复、可回滚的完整工程。

本任务必须解决：

1. 提供明确可用的 Web 研究者账号和安全的一次性密码交付方式；
2. 提供让获准人员从其他设备访问 Web 研究者后台的受控方案；
3. 让小程序研究者工作台具备经权限矩阵批准的全量移动研究功能，不用展示越权替代正式授权；
4. 修复训练记录、消息和历次反馈的服务端加载失败；
5. 完成微信一键登录和手机号快捷登录的云端配置、错误诊断、账号绑定与真机验收；
6. 为研究者平台转移、情感计算和社会网络在线分析、AI 自由问答、治疗性评估接入建立后续完整能力；
7. 保持参与者主闭环、非诊断边界、对象级权限、审计、隐私最小化和人工门禁不被破坏。

- 小程序已有 `pages/researcher-dashboard/index`，能够读取关系试点报名、详情、研究记录、报告、阶段性反馈和消息发送。

### 2.5 微信与手机号登录

## 3. 不可突破的边界

1. 不在仓库、文档、聊天截图、前端包或普通日志中写明文密码、管理员令牌、微信 Secret、手机号和 OpenID。
2. 不把展示越权改造成正式后端越权；展示越权只能是只读、合成或脱敏演示。
3. 不通过内网穿透公开真实参与者数据；临时公开链接只能使用合成数据、短时账号和自动到期策略。
4. 不把 Web 管理员全部功能机械复制到小程序；移动端只承载高频、短时、可审计工作流。
5. 不让情感计算、网络分析或 AI 问答生成诊断、人格、关系成败、疗效或危机处置结论。
6. 不让 AI 输出绕过风险规则、人工复核、消息审批和对象范围。
7. 不自动填写人工、伦理、心理、安全、微信资质、真机、云迁移和生产发布签字。
8. 不删除现有 API、数据库表、测试页或用户数据；回滚优先关开关、撤销域名、吊销凭据和恢复旧版本。

## 6. 自动开发固定循环

每个切片固定按以下顺序执行：

```text
事实快照 -> 写失败契约 -> 最小修复 -> 专项测试 -> 异常/并发/权限测试
-> SQLite/MySQL迁移与回滚 -> shared生成 -> Web/小程序验收
-> 测试云或设备证据 -> 全量回归 -> 文档 -> 独立Git提交
```

问题 loop：

- `code_failure`：保留失败输出，定位最小根因，修复后重跑专项和相关全量；
- `contract_drift`：停止依赖切片，先统一 API/shared/客户端和机器契约；
- `auth_scope_conflict`：默认保留严格权限，生成角色/对象范围差异报告，不扩大授权；
- `cloud_gateway_failure`：记录 HTTP 状态、content-type、request_id、部署指纹和脱敏日志，再判断应用、网关或数据库层；
- `wechat_external_gate`：生成配置/资质/真机证据包，不伪造微信成功响应；
- `human_gate`：继续可独立工程，相关能力保持关闭；
- `security_blocked`：立即停用对应入口、吊销临时凭据并保全审计。

4. 外部模型采用 provider adapter、超时、重试、熔断、费用上限、数据保留配置和供应商停用。
5. 高风险、诊断、法律、药物、危机和越权问题固定拒答/转人工；不能生成发送给参与者的正式反馈。
6. 记录脱敏会话元数据和人工评分，不记录密钥；删除和授权撤回可追踪到派生结果。

验收：批准知识、无来源问题、提示注入、敏感文本、供应商超时、预算耗尽、停用、删除和人工复核。

### T36-F16 治疗性评估 TA-03—TA-05 受控接入

实现：

1. 把“评估问题—共同核对材料—协作性反馈—一小步行动—随访”作为研究者工作对象，不把完整 TA 自动化。
2. 参与者可提出评估问题、确认/修改共享范围、查看版本化反馈和选择下一步；可以不同意或撤回。
3. 研究者使用结构化模板记录观察、证据、其他可能解释、不确定性、下一步和需人工讨论问题。
4. 反馈先由合格人员复核再发送；AI 只可草拟，不能确认或发送。
5. 儿童、伴侣、多人关系、高风险和真实诊断材料继续受 D01—D26、资质、督导与伦理门禁。
6. 成长仪表盘只记录变化和讨论线索，不生成单一疗效分数。

验收：同意、撤回、不同意、版本修订、共享范围、人工确认、风险阻断和审计；L0/L1 状态不能越级。

### T36-F17 全栈可靠性、隐私和安全收口

实现：

1. 所有新写接口增加幂等、并发版本、限速、对象范围和审计。
2. 消息、反馈、登录和分析任务进入既有可靠任务/死信/恢复工作台。
3. 增加密钥扫描、凭据轮换、隧道撤销、异常会话、批量读取和跨对象访问告警。
4. 日志、追踪和证据包执行原文、手机号、OpenID、token、密码、Cookie 和内部堆栈扫描。
5. 数据删除/撤回覆盖在线分析、AI 沙盒和治疗性评估派生记录。
6. 生产功能开关默认关闭；测试云通过也不自动打开生产。

### T36-F18 数据库迁移、备份恢复和非破坏性回滚

1. 为 F03/F12/F13/F16 必要表建立下一 schema 版本，先生成差异清单。
2. 验证 SQLite 空库、旧库、重复执行、部分失败；验证 MySQL 5.7 类型、默认值、索引宽度和复合索引。
3. 迁移前备份并记录 hash、表行数和 schema；隔离库完成恢复演练。
4. 回滚先关入口、撤销隧道、吊销账号/令牌、停止任务和切旧读路径；默认不 DROP 表、不删除审计和历史版本。
5. 生产迁移、恢复和回滚只能生成命令与证据包，未经批准不得自动执行。

### T36-F19 专项、全量和外部门禁验收

## 1. 执行原则

本清单承接任务二十至二十二，排除微信开发者工具、Android/iOS 真机、CloudBase/MySQL 正式迁移、订阅模板审核、正式发布和外部心理/伦理签字等人工事项。临时展示越权保持现状，不在本清单中关闭。

执行者必须遵守：

1. 先读取本文件和 `docs/00_当前事实基准/Claude计划模式.md` 对应任务状态，已完成项不得重复开发。
2. 每次只领取一个 `Txx-xx`；一个切片必须形成可演示的数据库/API/前端/测试闭环，或形成独立可验证的离线研究产物。
3. 每个切片完成后立即运行本节验收命令、更新状态表和证据路径；失败时停在当前切片，不扩散修改。
4. 不删除旧字段、旧 API、测试页或内容；字段变化先加兼容层，再迁移消费者。
5. 面向参与者的语言保持支持性、非诊断、非标签化；高风险内容不进入普通 AI 回答或训练卡推荐。
6. 外部数据集先登记授权、来源、哈希和允许用途，未通过授权门禁不得下载到仓库、训练或发布模型。
7. AI 自由问答默认关闭，只允许在合成案例和批准知识库上离线验证；不得默认使用参与者原始文本训练。

## 2. 自动执行状态机

每个子任务只使用以下状态：

```text
planned -> in_progress -> implemented -> verified -> documented
                         -> blocked_human_review
                         -> blocked_external_dependency
```

每次恢复时按以下顺序判断：

```text
检查 git status
-> 读取状态表
-> 检查验收证据是否存在
-> 已 verified/documented 则跳过
-> in_progress 则从第一个未通过验收项继续
-> planned 才开始新切片
```

## 3. 任务二十三：参与者主旅程收敛与协作式反馈闭环

目标：让参与者在任意时刻都知道“现在做什么、为什么、之后去哪里”，并可以明确纠正系统反馈。

### T23-00 主旅程事实基准

- 输出首页、记录、反馈、训练、成长和人工支持的入口图、状态来源和重复入口清单。
- 建立合成账号的黄金路径 fixture，不写真实参与者数据。
- 验收：文档可追踪到现有 API；核心链路自动测试仍通过。
- 阻塞：无，可立即开始。

### T23-01 今日任务最小闭环

- 复用现有 `training-plan.today_plan_items`，新增跨模块 Journey 聚合返回一个主任务、一个可选任务、继续上次进度和推荐依据摘要；不得建立第二套训练排序事实源。
- 已冻结首页布局决策：保持当前首页界面与原有区块，不删除、不移动“情绪天气”“测一测/情绪日记”“三步开始”“更多”“最近记录”和“阶段性反馈”。
- 只在当前“测一测/情绪日记”双入口之后、“三步开始”之前插入一张“今天的一小步”横向卡片；它是唯一根据个人状态动态变化的主行动，现有固定入口继续保留。
- 卡片最小结构为状态标签、行动标题、一行依据、一个主按钮和可选时长/完成状态；不在卡片内铺开完整训练、测评或报告内容。
- 无任务、加载、失败、暂停、已完成、有未完成记录、有到期训练和有新反馈均有明确状态；失败不得伪装成“暂无任务”。
- 治疗性评估子线只有在能力已获准、功能开关开启且存在进行中状态时，才可把“继续会前准备/补充资料/查看待确认反馈/完成回看”作为主行动；不新增长期首页模块。
- Web 参与者入口复用同一契约，不另造字段。
- 测试覆盖无记录、有未完成记录、有未完成练习、有新反馈、今日已完成、训练暂停和接口失败；增加当前首页区块仍存在且顺序未被意外改变的结构/视觉回归检查。
- 阻塞：T23-00。

### T23-02 协作式反馈评价闭环

- 在即时反馈、阶段性报告和训练建议中统一支持“符合、部分符合、不符合、让我不舒服”。
- 以统一 Feedback Ledger 保存来源、内容版本、评价、可选原因和时间；兼容读取已有 checkin 帮助度和关系假设核对，不覆盖原反馈。
- “让我不舒服”停止强化同一建议并进入人工复核信号；不自动推断风险或诊断。
- 参与者可更换一张备选训练卡，研究者只能查看授权范围内的评价摘要。
- 测试覆盖所有权、重复提交幂等、越权、历史版本和不适反馈。
- 阻塞：T23-00。

### T23-03 推荐排序使用显式反馈

- 只使用参与者明确评价、近期完成、训练节奏和治理状态调整排序。
- 不符合/不适的卡进入有期限冷却；不得永久封禁，除非内容被治理下线。
- 输出可解释的用户语言，不暴露规则 ID、权重或模型标签。
- 离线回放固定合成样例，保证排序可重复并不破坏高风险阻断。
- 阻塞：T23-02。

### T23-04 统一成长入口

- 建立一个成长入口，内部区分记录与练习、测评变化、关系探索和研究者反馈。
- 不合并不同量尺，不生成单一成长分数；数据不足只显示事实与空态。
- 原通用/关系仪表盘 URL 保留兼容跳转。
- 测试覆盖空数据、单模块、多模块和历史链接。
- 阻塞：T23-01。

### T23-05 视觉组件与回归收口

- 统一主任务卡、反馈评价、状态标签、空/加载/错误/重试组件和安全区。
- 每页一个主行动，风险确认和删除等高风险操作保留必要摩擦。
- 执行 375/430/768/1440 视口截图回归和键盘/可访问名称检查。
- 阻塞：T23-01、T23-02、T23-04。

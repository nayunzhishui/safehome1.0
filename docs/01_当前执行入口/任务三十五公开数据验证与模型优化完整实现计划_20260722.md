# 任务三十五：公开数据验证与模型优化完整实现计划

更新时间：2026-07-22

状态：`planned_not_started / dataset_rights_ethics_release_gates_pending`

本文是任务三十五的唯一执行入口。任务三十五继承任务二十九的合成离线基准和任务三十四的内容、数据与模型运营治理，不改写两项任务的历史完成状态。

## 1. 计划目标

任务三十五要建立一条可复现、可审计、可删除、可停用的公开数据验证与候选模型优化链路。工程完成不代表模型获准接触参与者，也不代表模型可以替换生产反馈规则。

本任务验证：

- 中文文本情绪识别的外部有效性
- 当前词典规则的覆盖率、错误类型和校准
- 增强规则、轻量分类器和可选中文编码模型的相对表现
- NetworkX网络指标的正确性、稳定性和规模性能
- 研究者只读影子比较、停用、删除和回滚能力

本任务不验证：

- 训练卡是否产生疗效
- 情绪分类是否等于诊断、人格、风险或关系质量
- 公开社交网络是否能够解释家庭关系
- 候选模型是否可以自动向参与者发送反馈
- 参与者原文是否可以未经独立同意用于训练

## 2. 当前事实基线

开始开发前必须复核以下事实：

1. 任务二十九已经完成240条中文合成事件、合成网络图、盲标、双人一致性、离线运行、复核、停用和审计工程。
2. `content/offline_benchmark_registry.json`中的外部数据仍为`metadata_review_only`，没有批准下载或训练。
3. `OFFLINE_EXTERNAL_INGEST_ENABLED`被代码强制关闭，`OFFLINE_PRODUCTION_REPLACEMENT_ALLOWED`必须保持关闭。
4. 当前情感计算主体是词典和规则分析，不是已经完成训练的机器学习模型。
5. 任务三十四已经建立模型卡、数据集卡、发布包、回放、漂移复核、停用和原子回滚治理。
6. 当前任何参与者原文、Word内容、聊天文本和关系记录都没有进入模型训练。

## 3. 候选公开数据及用途

| 数据集 | 优先级 | 允许申请的用途 | 禁止或暂缓用途 | 当前门禁 |
|---|---:|---|---|---|
| CPED | A | 中文对话情绪识别、上下文和标签映射基准 | 人格推断、治疗建议、家庭判断 | 影视文本内容权利书面复核 |
| GoEmotions | A | 英文域外压力测试、细粒度多标签参考 | 直接训练中文正式模型 | Reddit内容、偏差和归属复核 |
| SMP2020-EWECT | B | 中文短文本外部验证 | 未确认长期许可前训练或产品使用 | 向组织方取得书面许可 |
| CH-SIMS | C | 未来多模态研究参考 | 当前引入音视频训练 | 当前产品不采集音视频 |
| SNAP具体图数据 | B | 网络算法正确性、稳定性和性能 | 家庭质量、参与者或关系推断 | 逐数据集许可与内容权利复核 |
| NetworkX内置图 | A | 数学正确性和确定性回归 | 真实社会含义解释 | 核对源数据说明 |

“公开”不等于“可训练”。数据集主页、代码许可证、原始文本权利和平台条款必须分别登记。

## 4. 完整任务拆分

### T35-F00 冻结研究问题与分析方案

实现：

1. 固定情绪识别、域外拒绝和网络算法三类研究问题。
2. 保存当前词典、规则、标签、合成案例、网络参数、代码提交、依赖、随机种子和SHA-256。
3. 冻结主要指标、次要指标、严重错误定义、统计方法和停止条件。
4. 声明训练卡推荐、治疗效果和家庭关系推断不属于本任务结论。

交付物：

- `content/offline_benchmark_protocol.json`
- `content/offline_baseline_manifest.json`
- 预注册式分析计划和数据流图

验收：基线制品不可原地覆盖，测试集结果不能反向改变标签映射或分析标准。

### T35-F01 完成数据集卡和权利审批状态机

实现：

1. 为CPED、GoEmotions、SMP2020-EWECT和拟选SNAP子数据集补齐数据集卡。
2. 登记来源、论文、版本、许可证快照、内容权利、平台条款、允许用途、禁止用途、删除方法和负责人。
3. 统一状态：`metadata_only`、`rights_review_pending`、`evaluation_approved`、`training_approved`、`suspended`、`deleted`。
4. 将“允许评测”和“允许训练”拆成两个独立人工批准。
5. 系统只生成证据包，不自动填写人工、伦理或法律签名。

验收：未达到对应批准状态时，下载、训练和衍生模型操作全部拒绝并写审计。

### T35-F02 建立隔离导入、哈希和删除链路

实现：

1. 原始文件进入Git忽略的隔离目录，不进入生产数据库和项目提交。
2. 下载前检查环境、数据集允许名单、批准状态和磁盘空间。
3. 下载后计算SHA-256、文件大小、行数、编码和压缩包清单。
4. 原始文件转为只读，派生数据保存来源哈希和转换版本。
5. 删除流程覆盖原始文件、派生文件、缓存、模型和运行索引，并生成删除证明。
6. 网络失败、哈希不匹配、解压失败和磁盘不足均保留可恢复状态。

配置原则：

```text
APP_ENV=offline_research
OFFLINE_EXTERNAL_DATASET_ALLOWLIST=approved_dataset_ids
OFFLINE_PRODUCTION_REPLACEMENT_ALLOWED=0
```

不得通过一个全局布尔值绕过数据集卡和环境限制。公开数据下载只由离线命令执行，不提供普通Web下载接口。

### T35-F03 建立统一适配、去重和数据划分

统一记录结构：

```json
{
  "sample_id": "source_scoped_id",
  "text": "normalized_text",
  "context": [],
  "source_dataset": "dataset_id",
  "source_split": "train_dev_or_test",
  "source_labels": [],
  "project_labels": [],
  "mapping_status": "mapped_partial_or_unmapped",
  "group_id": "dialogue_show_or_source_group"
}
```

实现：

1. 建立CPED、GoEmotions、SMP和网络图适配器。
2. 校验字段、标签、编码、空文本、重复ID、缺失值和不可能值。
3. 做精确去重和近重复检测，禁止同一对话、剧集、角色或来源组跨数据划分泄漏。
4. 优先保留官方训练、验证、测试划分；没有可靠划分时按来源组划分。
5. 记录每次转换的输入哈希、输出哈希、样本流失及原因。

验收：转换前后样本数量可核对，原始标签不被覆盖，任何测试样本不能进入调参输入。

### T35-F04 冻结项目标签映射

项目标签继续使用非诊断类别：

```text
anxiety / fear / anger / irritation / sadness / helplessness
guilt / shame / calm / positive / unmapped
```

实现：

1. 来源标签保留原值，项目标签写入独立映射字段。
2. 不能等值的标签保留`unmapped`，不为提高指标强行合并。
3. 多标签数据保持多标签，不先压成单标签。
4. CPED人格、性别和年龄字段不进入参与者推断。
5. 标签映射由心理专业人员和数据人员分别复核并生成新版本。

验收：映射版本、哈希、审批人和变更原因可追溯；查看测试结果后不得修改同一版本映射。

### T35-F05 运行当前规则的外部基线

主要指标：

- Macro-F1
- 每类精确率、召回率和F1
- 混淆矩阵
- 覆盖率、`unmapped`率和拒绝率
- Expected Calibration Error或Brier Score
- 严重错误率
- 1,000次配对bootstrap置信区间

专项切片：

- 否定、程度、转折、反问和讽刺
- 混合情绪和多轮上下文
- 亲子称谓、行为与情绪错配
- 英文、影视、微博和域外文本
- 长文本、短文本和低一致性文本

验收：运行只保存必要的聚合指标、样本ID和错误类型，不把完整公开原文写入API、数据库或普通日志。

### T35-F06 建立项目域专家金标准

实现：

1. 将现有240条合成案例升级为400至600条项目域案例。
2. 新案例由专家撰写，不使用参与者原文、聊天内容或Word原始敏感文本。
3. 两名标注者独立标注情绪、效价、唤醒、反射弧节点、是否允许自动判断和分歧原因。
4. 盲标界面隐藏生成标签和另一名标注者结果。
5. 分歧由第三名复核者仲裁，但保留原始分歧记录。

冻结门槛：

- 完整双标案例不少于200条
- 情绪Cohen's Kappa不低于0.70
- 平均效价差不高于0.25
- 平均唤醒差不高于0.20

人工金标准未发布前，任何合成生成标签都不能写成真实金标准。

### T35-F07 优化增强规则候选

实现：

1. 增加否定窗口、程度词、转折后半句权重和多词短语。
2. 支持多情绪、冲突标签、低置信拒绝和`unmapped`。
3. 多轮上下文使用明确衰减，不把历史情绪永久传播到当前句。
4. 只使用训练集和验证集扩充词典和调阈值。
5. 新词典、参数和规则形成独立不可变制品。

验收：能够复现当前基线；关闭候选开关后完全恢复旧规则。

### T35-F08 训练可解释轻量候选模型

首选方案：中文字符2至5 gram TF-IDF，加Logistic Regression或Linear SVM，多标签任务使用One-vs-Rest。

实现：

1. 固定数据、特征、正则化、随机种子和依赖版本。
2. 训练集拟合，验证集调参，测试集只做锁定后的最终运行。
3. 输出每类特征、阈值、校准参数、模型大小和CPU推理时延。
4. 对类别不平衡采用预先登记的权重或采样策略。
5. 模型制品写入任务三十四发布包体系，但状态保持`research_candidate`。

验收：从干净输入能够重训并得到允许误差范围内的相同指标和制品哈希。

### T35-F09 条件式评估中文编码模型

本任务不是强制训练深度模型。只有规则候选和轻量模型未达到冻结标准，且权利、算力、模型许可证和研究用途均获批准时，才执行本步骤。

实现要求：

1. 登记基础模型来源、版本、许可证、模型卡和已知偏差。
2. 使用冻结数据划分、随机种子、早停和资源上限。
3. 不使用生成式模型直接生成参与者心理反馈。
4. 不使用参与者原文微调。
5. 报告不同随机种子、校准、域外拒绝、时延、内存和碳/算力记录。

未达到进入条件时，本步骤应记录为`not_started_by_gate`，不能伪造训练结果。

### T35-F10 完成统计比较与候选决策

候选准入值必须在查看最终测试结果前冻结。初始建议值：

1. 项目域Macro-F1相对基线绝对提升不低于0.03。
2. 配对bootstrap差异的95%置信区间下界高于0。
3. 恐惧、愤怒、悲伤等重点类别召回下降不超过0.02。
4. 严重错误率不得高于基线。
5. 校准误差不得高于基线。
6. 域外文本具有明确拒绝能力。
7. 公开数据和项目域金标准的改进方向一致。

决策优先级：心理安全、严重错误、重点类别召回、校准、Macro-F1、总准确率。

结果分为：`stop`、`changes_required`、`research_candidate`。系统不能自动把候选改为生产模型。

### T35-F11 验证网络算法

实现：

1. 验证degree、weighted strength、betweenness、closeness、PageRank、连通分量、社区和modularity。
2. 与NetworkX参考实现比较确定性指标。
3. 测试节点重命名、边顺序、正负5%与10%边权扰动、多支持度、多共现窗口和多随机种子。
4. 报告社区Adjusted Rand Index、Normalized Mutual Information、中心节点Top-K Jaccard和bootstrap稳定性。
5. 记录节点、边规模增长后的时间和内存。
6. 小样本节点和边继续执行隐私抑制。

边界：SNAP只验证算法，不训练家庭关系模型；语义共现图不是人际关系图；时间变化不解释为关系改善或恶化。

### T35-F12 建立研究者只读影子比较

影子模式：生产规则照常运行，候选模型并行计算，候选结果不发送参与者，不改变训练卡推荐和风险判断。

Web工作台展示：

- 数据集卡和权利状态
- 基线与候选聚合指标
- 混淆矩阵和错误切片
- 置信度、拒绝率和版本
- 研究者人工复核结论
- 停用、删除和回滚证据

权限：

- researcher：查看允许范围内的运行和保存复核
- supervisor：查看全部聚合运行并作专业复核
- admin：管理离线运行、停用和删除
- participant：无公开数据、候选模型或影子结果权限

小程序不增加候选模型入口，不展示候选结果。

### T35-F13 补齐数据库、shared、API和审计

数据库优先复用：

- `offline_dataset_cards`
- `offline_benchmark_runs`
- `offline_benchmark_reviews`
- 任务三十四模型和发布治理表
- `audit_logs`

只有现有结构无法表达制品、候选比较和影子批次时，才规划非破坏性024迁移，候选表为：

- `offline_dataset_artifacts`
- `offline_model_candidates`
- `offline_model_comparisons`
- `offline_shadow_batches`

shared与API只返回数据集元数据、聚合指标、版本、状态和证据路径。API禁止返回原始公开文本、训练文件和模型二进制正文。

关键审计动作：登记、批准状态同步、导入、哈希失败、运行、训练、比较、复核、停用、删除、回滚和影子批次关闭。

### T35-F14 完成异常恢复、迁移和回滚

异常恢复覆盖：

- 网络中断和断点续传
- 哈希不匹配和压缩包损坏
- 编码、字段和标签异常
- 训练中断和检查点恢复
- 磁盘不足和资源超限
- 数据集被撤回或许可证变化
- 候选严重错误和影子运行停用

回滚要求：

1. 一键关闭全部外部导入、训练和影子开关。
2. 恢复旧词典和生产规则。
3. 删除公开原始、派生和候选制品并保留删除证明。
4. 保留审计、聚合指标和人工决定，不删除参与者既有记录。
5. 迁移脚本重复执行安全，回滚不自动DROP表。

### T35-F15 自动化执行器和完整验收

新增任务三十五注册表和执行器，支持：`plan`、`run`、`resume`、`verify`和`report`。

执行器必须：

- 只使用参数数组执行命令
- 保存命令、返回码、起止时间、数据与代码哈希
- 仅跳过命令一致且已成功的步骤
- 数据集或命令漂移时阻断续跑
- 不自动下载未批准数据
- 不自动签署权利、伦理、心理、安全或生产批准
- 不自动替换生产模型

专项验收：

1. 未批准数据拒绝下载和训练。
2. 哈希错误拒绝运行。
3. 测试集不参与调参。
4. 标签映射不可静默丢失。
5. 去重和来源组隔离有效。
6. 训练和统计结果可复现。
7. 原始文本不进入普通日志、数据库和API。
8. participant不能访问研究接口。
9. 停用、删除和回滚有效。
10. 风险规则、人工队列和生产反馈不被候选覆盖。

全量验收：

- 后端全量测试
- 内容与数据集卡校验
- 数据库迁移重复执行和保守回滚
- shared与API机器契约
- 权限注册表和审计
- Web typecheck、build和桌面/移动E2E
- 小程序结构、语法和核心闭环回归
- T23至T34冻结兼容检查
- 数据删除、停用和失败恢复演练
- `git diff --check`

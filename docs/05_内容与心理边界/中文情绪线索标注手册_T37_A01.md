# 中文情绪线索标注手册（T37-A01）

版本：2026-07-28-t37-a01-v1  
状态：工程完成，心理与方法专家逐项审查待完成

## 1. 项目问题

本任务只回答：一条中文自我记录中，明确表达了哪些情绪线索、强度、否定或混合状态，哪些内容需要真人进一步了解。

标注结果不等于诊断、人格、危机概率、关系优劣、治疗效果或未来行为预测。安全线索与情绪标签分开记录。

## 2. 标注单位与顺序

1. 阅读完整记录和允许提供的最小上下文，不先搜关键词。
2. 标记原文中支持判断的最小连续片段。
3. 最多选择三个情绪标签；没有足够证据时选择`unknown`。
4. 分别判断强度、肯定/否定/不确定、是否混合。
5. 独立判断是否出现安全线索和是否需要真人了解。
6. 写一句可复核理由，不解释潜意识，不推断关系类型。

## 3. 强度与否定

- 0：未表达、明确否定或无法判断。
- 1：轻微、间接或短暂。
- 2：明确，但文本未显示明显干扰。
- 3：强烈或反复，已影响当下行动。
- 4：极强，伴随明显失控、持续受困或紧急安全线索。

否定只作用于其语法范围。“我不是生气，只是担心”应把愤怒记为否定，把担心记为肯定。双重否定、反讽和方言无法稳定判断时使用`unknown`并选择“需真人了解”。

## 4. 混合情绪、未知与真人了解

- 同一记录可同时存在最多三种有直接证据的情绪。
- 不要为凑满标签推断隐藏情绪。
- 只有事件、指代不清、反讽、隐喻、文化语境不足时使用`unknown`。
- 安全线索、歧义、方言、超过三种情绪或双人分歧时选择“需真人了解”。
- “需真人了解”表示信息不足或需要优先核对，不表示高风险结论。

## 5. 安全线索

出现自伤、自杀、伤人、严重暴力、虐待、急性失控或无法保证安全的明确表达时，单独标记`crisis_expression`。该字段不是情绪标签，也不是风险概率；不得仅凭一个关键词自动得出危机结论。系统必须保留原证据和人工复核入口。

## 6. 边界与反例

完整边界样例和反例位于`content/emotion_annotation_examples.json`。标注者必须特别避免：

- 把准备行为标成焦虑；
- 把“不合理”的观点标成愤怒；
- 把哭泣直接等同悲伤；
- 把“不知道答案”标成无助；
- 把“谢谢”标成积极情绪；
- 把联系频率解释成关系质量。

## 7. 分歧处理

两名标注者独立工作，看不到对方答案和模型预测。主标签、否定范围、安全线索有分歧，或强度相差两级以上时进入第三人裁决。裁决必须保留两份原始答案、裁决结果、理由、引用条款和手册版本；无法确定时保留`unknown`。

## 8. 发布边界

72词规则表继续作为工程测试基线，不是人工金标准。公开数据只用于预训练比较或方法演练；合成数据只用于流程和契约测试。专家逐项审查、双人标注和裁决证据未完成前，不得把本手册标记为正式心理学批准。

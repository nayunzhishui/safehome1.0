# 小样本用户研究试用任务脚本

创建日期：2026-05-26

项目：`safehome1.0 / 安心陪伴 / ReadFeedback`

本文档用于 5-8 人小样本可用性测试。目标是确认家长是否能理解并走通“目标 -> 记录 -> 反馈 -> 训练 -> 打卡 -> 周报/督导”的核心闭环，以及是否感到系统表达足够非诊断、非评判、支持性。

## 1. 测试目标

本轮只验证试点前可用性，不验证治疗效果，不做诊断评估。

重点观察：

1. 家长能否理解“安心陪伴”是陪伴练习支持系统；
2. 家长是否知道下一步该点哪里；
3. 家长是否能顺利完成一次记录和练习；
4. 家长是否觉得反馈文案被评价、被责备或太临床；
5. 家长是否理解人工督导不是实时危机服务；
6. 研究人员是否能在 Web 后台找到对应记录、反馈、打卡和导出入口。

## 2. 参与者建议

建议人数：5-8 人。

建议类型：

1. 有小学或初中孩子的家长；
2. 近期遇到过亲子沟通压力的家长；
3. 能正常使用微信小程序；
4. 愿意边使用边说出自己的想法。

暂不建议纳入：

1. 正处于急性危机中的家庭；
2. 需要立即专业干预或安全处置的个案；
3. 只想获得诊断、治疗或危机处理建议的参与者。

## 3. 测试前说明

主持人可以使用以下说明：

```text
今天我们想了解这个系统是否容易理解、容易操作、表达是否让人舒服。它不是诊断工具，也不替代心理咨询、医学诊断、危机干预或法律判断。请你按照自己的真实感受操作，如果哪里看不懂、点不动、或者感觉不舒服，可以直接说出来。
```

## 6. 访谈问题

测试结束后询问：

1. 你会在什么情况下使用它？
2. 哪一步最容易理解？
3. 哪一步最想跳过？
4. 哪句话让你觉得被支持？
5. 哪句话让你觉得被评价或不舒服？
6. 如果只保留一个功能，你最希望保留哪个？
7. 如果让你明天继续用一次，最大的阻碍是什么？

## 7. 判断标准

优先修复：

1. 家长不知道下一步点哪里；
2. 家长觉得反馈像评价或责备；
3. 家长觉得记录表单太长；
4. 家长误以为系统能诊断或处理危机；
5. 后台研究人员找不到核心数据；
6. 移动端出现明显溢出、遮挡或按钮不可点。

暂不纳入本轮：

1. 正式登录注册；
2. 复杂权限；
3. 真实 AI 自由问答；
4. 大规模量表研究；
5. 数据库结构调整；
6. 商业化部署。

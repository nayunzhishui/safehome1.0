# 匿名用户 ID 与试用数据隔离方案

更新时间：2026-06-04

当前项目尚未做正式登录注册，也未接入微信授权。为避免真实试用数据全部写入 `demo-parent`，前端使用本地匿名 ID 做数据隔离。

## 1. 定位

匿名 ID 不是身份认证，不证明用户真实身份。

它只用于：

- 区分不同试用设备或浏览器的数据；
- 让目标、记录、反馈、打卡、周报等可以按用户聚合；
- 降低所有数据混入同一个测试用户的风险。

## 2. 小程序匿名 ID

存储位置：

```text
wx storage
```

存储 key：

```text
safehome_anonymous_user_id
```

生成格式：

```text
wx_user_时间戳_随机片段
```

清除小程序缓存后会生成新的匿名 ID。

## 3. Web 匿名 ID

存储位置：

```text
localStorage
```

存储 key：

```text
safehome_anonymous_user_id
```

生成格式：

```text
web_user_时间戳_随机片段
```

清除浏览器缓存或 localStorage 后会生成新的匿名 ID。

## 4. 不使用的信息

试用阶段不要把以下信息作为主键：

- 姓名；
- 手机号；
- 身份证号；
- 学校；
- 班级；
- 真实住址；
- 家庭关系标签。

如需记录试用编号，优先使用研究编号或匿名编号。

## 5. 研究导出

研究导出默认匿名化：

- 学生画像导出使用 `anonymous_id`；
- records 导出使用 `anonymous_id`；
- 家长双量表使用 `anonymous_id` 和研究编号；
- 自由文本和联系方式属于敏感数据，对外使用前必须再次脱敏。

## 6. 正式上线前

正式上线前仍需要补充：

1. 正式账号或授权机制；
2. 用户身份和数据归属规则；
3. 撤回授权和删除数据流程；
4. 管理员权限和操作审计；
5. 小程序发布前隐私合规检查。

匿名 ID 只是试用阶段的数据隔离措施，不能替代正式权限系统。

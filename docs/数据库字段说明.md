# 数据库字段说明

本文档定义安心陪伴 MVP 1.0 的 SQLite 第一版数据表。字段命名采用英文 snake_case，展示文案使用中文。

## 1. `users`

保存家长弱身份信息或测试用户信息。第一版不采集强身份信息。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 用户 ID |
| `nickname` | TEXT | 昵称或测试编号 |
| `role` | TEXT | `parent`、`student`、`admin` |
| `source` | TEXT | 来源渠道 |
| `created_at` | TEXT | 创建时间 |
| `updated_at` | TEXT | 更新时间 |

## 2. `goals`

保存目标设定。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 目标 ID |
| `user_id` | TEXT | 用户 ID |
| `scene` | TEXT | 高频亲子冲突场景 |
| `smart_goal` | TEXT | 7 天 SMART 小目标 |
| `motivation` | TEXT | 改变动机 |
| `start_date` | TEXT | 开始日期 |
| `status` | TEXT | `active`、`done`、`paused` |
| `created_at` | TEXT | 创建时间 |
| `updated_at` | TEXT | 更新时间 |

## 3. `emotion_diaries`

保存情绪事件记录。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 记录 ID |
| `user_id` | TEXT | 用户 ID |
| `goal_id` | TEXT | 关联目标 ID |
| `event_time` | TEXT | 事件发生时间 |
| `scene` | TEXT | 亲子互动或冲突场景 |
| `event_description` | TEXT | 具体事件 |
| `parent_emotion` | TEXT | 家长主要情绪 |
| `parent_emotion_intensity` | INTEGER | 家长情绪强度，1-10 |
| `child_emotion` | TEXT | 孩子主要情绪 |
| `child_emotion_intensity` | INTEGER | 孩子情绪强度，1-10 |
| `automatic_thought` | TEXT | 自动想法 |
| `body_sensation` | TEXT | 身体感觉 |
| `behavior` | TEXT | 当时行为或回应 |
| `raw_text` | TEXT | 原始记录文本 |
| `created_at` | TEXT | 创建时间 |
| `updated_at` | TEXT | 更新时间 |

## 4. `feedback_results`

保存即时反馈结果。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 反馈 ID |
| `user_id` | TEXT | 用户 ID |
| `diary_id` | TEXT | 情绪事件记录 ID |
| `tags_json` | TEXT | 标签 JSON |
| `trigger_summary` | TEXT | 触发点摘要 |
| `pattern_summary` | TEXT | 互动模式解释 |
| `supportive_feedback` | TEXT | 支持性反馈 |
| `alternative_response` | TEXT | 替代回应建议 |
| `recommended_card_ids_json` | TEXT | 推荐训练卡 ID JSON |
| `risk_level` | TEXT | `low`、`medium`、`high` |
| `created_at` | TEXT | 创建时间 |

## 5. `training_cards`

保存训练卡内容。第一版也可以从 `content/training_cards.json` 读取并同步到数据库。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 训练卡 ID |
| `type` | TEXT | 卡片类型 |
| `title` | TEXT | 卡片标题 |
| `purpose` | TEXT | 使用目的 |
| `steps_json` | TEXT | 操作步骤 JSON |
| `tags_json` | TEXT | 适用标签 JSON |
| `example` | TEXT | 示例话术 |
| `enabled` | INTEGER | 是否启用，1/0 |
| `version` | TEXT | 内容版本 |
| `created_at` | TEXT | 创建时间 |
| `updated_at` | TEXT | 更新时间 |

## 6. `checkins`

保存练习打卡。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 打卡 ID |
| `user_id` | TEXT | 用户 ID |
| `card_id` | TEXT | 训练卡 ID |
| `diary_id` | TEXT | 关联情绪记录 |
| `completed` | INTEGER | 是否完成，1/0 |
| `emotion_before` | INTEGER | 练习前情绪强度，1-10 |
| `emotion_after` | INTEGER | 练习后情绪强度，1-10 |
| `reflection` | TEXT | 简短复盘 |
| `created_at` | TEXT | 创建时间 |

## 7. `assessment_results`

保存小程序“测一测”中量表和工作表的填写结果。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 测一测结果 ID |
| `user_id` | TEXT | 用户 ID |
| `worksheet_id` | TEXT | 工作表 ID |
| `worksheet_title` | TEXT | 工作表标题 |
| `category` | TEXT | 分类 |
| `answers_json` | TEXT | 用户答案 JSON |
| `scores_json` | TEXT | 分数或维度结果 JSON |
| `total_score` | INTEGER | 数值题合计，记录型工作表可为空 |
| `result_summary` | TEXT | 支持性结果摘要 |
| `created_at` | TEXT | 创建时间 |

说明：

- 第一版不采集姓名、手机号、身份证等强身份信息。
- 结果用于自我观察和练习记录，不构成诊断。
- 原 PDF 为图片型，完整题项需要后续逐页转录补齐。

## 8. `weekly_reports`

保存周度报告。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 周报 ID |
| `user_id` | TEXT | 用户 ID |
| `week_start` | TEXT | 周开始日期 |
| `week_end` | TEXT | 周结束日期 |
| `frequent_scenes_json` | TEXT | 高频场景 JSON |
| `frequent_emotions_json` | TEXT | 高频情绪 JSON |
| `common_patterns_json` | TEXT | 常见互动模式 JSON |
| `completed_cards_json` | TEXT | 已完成训练卡 JSON |
| `next_week_suggestion` | TEXT | 下周建议 |
| `created_at` | TEXT | 创建时间 |

## 9. `supervision_requests`

保存人工督导请求。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT PRIMARY KEY | 督导请求 ID |
| `user_id` | TEXT | 用户 ID |
| `diary_id` | TEXT | 关联情绪记录 |
| `message` | TEXT | 用户提交内容 |
| `contact` | TEXT | 可选联系方式 |
| `risk_hint` | TEXT | 用户自述风险提示 |
| `risk_level` | TEXT | 系统或人工风险等级 |
| `status` | TEXT | `pending`、`replied`、`closed` |
| `supervisor_reply` | TEXT | 人工回复 |
| `created_at` | TEXT | 创建时间 |
| `replied_at` | TEXT | 回复时间 |

## 10. 数据边界

- 第一版不采集姓名、手机号、身份证等强身份字段。
- 任何联系方式字段都应明确告知用途。
- 高风险文本只用于提示人工复核或转介，不由 AI 自动处理。
- 导出数据应尽量使用匿名 ID。

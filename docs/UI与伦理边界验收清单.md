# UI 与伦理边界验收清单

创建日期：2026-05-26

项目：`safehome1.0 / 安心陪伴 / ReadFeedback`

本文档用于每轮 UI 收口和试点前人工验收。目标是把问题记录为三类：看不懂、点不动、不舒服。

## 1. 验收原则

本项目所有页面都应符合：

1. 非诊断；
2. 非标签化；
3. 支持性；
4. 非评判；
5. 聚焦具体事件和可练习动作；
6. 不承诺替代心理咨询、医学诊断、危机干预或法律判断。

## 5. 心理与伦理文案检查

允许表达：

1. `可能`;
2. `看起来`;
3. `这次记录中可以看到`;
4. `可以尝试`;
5. `练习位置`;
6. `支持性反馈`;
7. `补充理解`;
8. `需要时寻求现实支持或专业帮助`。

需要替换或避免的表达：

1. 直接判断孩子、家长或家庭；
2. 诊断性疾病表述；
3. 人格或家庭标签；
4. 责备、羞辱或命令式表达；
5. 承诺系统能处理危机；
6. 把周报写成成绩排名；
7. 把打卡写成评分或考核。

## 6. 页面重点边界

### 6.1 AI反馈页

必须体现：

1. 反馈是支持性参考；
2. 不评价谁对谁错；
3. 识别到的是一次记录中的互动线索；
4. 下一步是可练习的小动作。

### 6.2 周报页

必须体现：

1. 周报是复盘；
2. 不排名；
3. 不评分；
4. 不给疾病或人格结论。

### 6.3 人工督导页

必须体现：

1. 人工督导是补充理解；
2. 不是实时危机服务；
3. 不替代专业服务；
4. 出现安全风险时应寻求现实支持。

### 6.4 导出页

必须体现：

1. 导出前先检查脱敏；
2. 长文本可能包含可识别信息；
3. 导出文件只给授权人员使用；
4. 不暗示数据可以随意外发。

## 7. 修复优先级

P0 立即修复：

1. 按钮不可点击；
2. 主流程无法继续；
3. 文案明显诊断化或责备；
4. 移动端关键内容被遮挡；
5. 高风险边界表达错误。

P1 本轮修复：

1. 文字溢出；
2. 卡片拥挤；
3. 状态色不统一；
4. 空状态不清楚；
5. 用户不知道下一步。

P2 后续优化：

1. 插画细节；
2. 动效；
3. 更细的筛选；
4. 更完整的数据分析；
5. 正式权限系统。

# 提交前检查清单

更新时间：2026-06-03

项目：`safehome1.0 / 安心陪伴 / ReadFeedback`

本清单用于当前 MVP 1.1 开发轮次提交前检查。它只整理提交步骤，不新增功能，不修改数据库，不新增后端 API。

## 1. 提交前必须先看状态

先运行：

```powershell
cd D:\codex\workspace\safehome1.0
git status --short
```

重点确认：

1. 是否有不属于本轮的文件混入；
2. 是否有本地运行产物；
3. 是否有数据库文件；
4. 是否有依赖目录；
5. 是否有临时缓存。

## 2. 禁止提交的文件和目录

不要提交：

```text
node_modules
dist
*.db
*.sqlite
venv
.venv
__pycache__
*.pyc
.pytest_cache
```

如果 `git status --short` 中出现以上内容，先暂停提交，确认来源后再处理。

## 3. 推荐分批暂存

不要直接使用：

```powershell
git add .
```

建议按以下范围分批检查和暂存。

### 3.1 小程序改动

```powershell
git add apps/miniprogram/app.json
git add apps/miniprogram/pages/diary-form
git add apps/miniprogram/pages/feedback-result
git add apps/miniprogram/pages/training-card
git add apps/miniprogram/pages/checkin
git add apps/miniprogram/pages/home
git add apps/miniprogram/pages/weekly-report
git add apps/miniprogram/pages/supervision
```

暂存后检查：

```powershell
git diff --cached --stat
git diff --cached -- apps/miniprogram
```

### 3.2 网站后台改动

```powershell
git add apps/web/src/main.tsx
git add apps/web/src/styles.css
git add apps/web/src/pages
```

暂存后检查：

```powershell
git diff --cached --stat
git diff --cached -- apps/web/src
```

### 3.3 文档改动

```powershell
git add AGENTS.md
git add docs
```

暂存后检查：

```powershell
git diff --cached --stat
git diff --cached -- docs
```

## 4. 提交前验证命令

后端测试：

```powershell
cd D:\codex\workspace\safehome1.0
python -m pytest backend\tests -q
```

内容库校验：

```powershell
cd D:\codex\workspace\safehome1.0
python backend\scripts\validate_content.py
```

网页端构建：

```powershell
cd D:\codex\workspace\safehome1.0\apps\web
npm run build
```

小程序 JS 语法检查：

```powershell
cd D:\codex\workspace\safehome1.0
Get-ChildItem -Path apps/miniprogram -Recurse -Filter *.js | ForEach-Object { node --check $_.FullName }
```

小程序 JSON 检查：

```powershell
cd D:\codex\workspace\safehome1.0
Get-ChildItem -Path apps/miniprogram -Recurse -Filter *.json | ForEach-Object { Get-Content -Raw -LiteralPath $_.FullName | ConvertFrom-Json | Out-Null }
```

风险文件检查：

```powershell
git status --short | Select-String -Pattern 'node_modules|dist|\.db$|\.sqlite$|venv|__pycache__|\.pyc$|\.pytest_cache'
```

如果风险文件检查有输出，先不要提交。

## 6. 建议提交拆分

如果要拆成多个提交，建议顺序：

1. 小程序 MVP 1.1 闭环增强；
2. 网站后台页面补齐；
3. 文档和验收清单更新。

每次提交前都重新运行：

```powershell
git status --short
```

并确认没有本地运行产物混入。

### 具体修改要求

```text

```

示例逻辑：

```python
def get_request_user_id() -> str | None:
    payload = request.get_json(silent=True) if request.method in {"POST", "PUT", "PATCH"} else None
    return (
        request.args.get("user_id")
        or request.headers.get("X-User-Id")
        or (payload or {}).get("user_id")
    )

def require_admin_or_owner(record_user_id: str | None) -> str:
    if request.headers.get("X-Admin-Token"):
        return require_admin_token()
    request_user_id = get_request_user_id()
    if record_user_id and request_user_id and str(record_user_id) == str(request_user_id):
        return str(request_user_id)
    raise ValueError("需要后台令牌或匹配的匿名 user_id")
```

使用规则：

```text
1. 后台列表接口必须要求 X-Admin-Token。
2. 用户自己的详情接口允许 X-Admin-Token 或匹配 user_id。
3. POST followup/sandplay/action 等写入接口必须校验所属 user_id。
```

### 具体修改要求

在 `backend/scripts/validate_content.py` 中新增：

```python
FORBIDDEN_TERMS = [
    "人格障碍",
    "潜意识说明",
    "治疗保证",
    "保证改善",
    "立即治愈",

    "治疗",
    "危机干预",

```

注意：

```text
“诊断”“治疗”“危机干预”不能简单全局禁止，因为合法边界文案会写“不构成诊断”“不替代心理咨询/危机干预”。
检测时要区分：
- 允许：不构成诊断、不替代心理咨询、不替代危机干预
- 不允许：系统诊断、专业诊断、治疗保证、立即改善
```

新增校验：

```text
1. training_cards.cards[].id 不重复。
2. feedback_rules.rules[].id 不重复。
```

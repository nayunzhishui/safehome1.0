## 三、已经实现的关键整改

### 1. 风险复核审计身份

`backend/routes/risk_review.py` 与 `backend/services/risk_review_service.py`：

- audit actor 只能来自认证身份；
- 客户端 `reviewer_id` 只能与当前 actor 相同，否则 403；
- 复核审计增加 `audit_identity_source=authenticated_actor`。

### 2. 风险/危机分流

`backend/services/risk_service.py`：

- 保留旧 `risk_level` 兼容；
- 新增 `safety_route`：`standard / human_support_review / human_review / urgent_human_review`；
- 新增 `review_priority`、即时性/方法/可获得性/历史否定/保护因素上下文；
- 否定/历史/保护因素不会由简单规则自动降级；
- 继续明确：不构成诊断、危机评估、自杀概率预测或治疗处置依据。

### 3. 未成年人方案 A+B

`backend/services/participant_safeguard_service.py`：

- 不收集完整出生日期，只确认 `14_or_older / under_14`；
- ≥14 岁完成确认后可进入普通心理数据流程；
- <14 岁要求 active family link + guardian consent + minor assent；
- 任一撤回后重新阻断；
- `/auth`、`/consent`、`/family`、`/risk`、`/supervision` 不被保护门禁阻断。

相关 API：

- `POST /api/consent/age-confirmation`
- `POST /api/consent/guardian-sensitive-processing`
- `POST /api/consent/minor-assent`
- `GET /api/consent/participant-safeguards`

### 4. production 身份收敛

- `X-Admin-Token` 只保留 development/testing 兼容；production 返回拒绝。
- Web `adminToken.ts` 在 production 不再保存/发送 legacy token。
- 正式身份使用 Bearer/CloudBase/正式后台账号。
- Showcase 逻辑原样保留，不属于本轮认证收敛对象。

### 5. 后端架构

- 架构风格冻结为 modular monolith；不拆微服务。
- 四个领域：participant / research / safety-governance / internal-rd。
- 新增 `config/runtime_architecture.json`。
- 新增 `backend/scripts/audit_runtime_architecture.py`。
- 新的 Task 编号运行时模块被禁止；历史 Task37 代码逐步兼容迁移。
- 计算契约已新增 `computation_contract_service.py`，旧 `task37_contract_service.py` 仅做 compatibility shim。

### 6. 数据库

新增：

- `backend/services/referential_integrity_service.py`
- `backend/scripts/audit_referential_integrity.py`

先持续审计高价值 `*_id` 关系，避免未经历史数据清洁度确认就直接重建大量 FK。

### 7. Web

- production legacy admin token 已禁用。
- 新增 `apps/web/src/services/domainApi.ts`，为 participant / research / governance / internal-R&D 提供分域 facade。
- 旧 `safehomeApi.ts` 保留为兼容层，但冻结继续膨胀。
- 新增 `scripts/audit_web_domain_boundaries.mjs`，新 Web 文件不得再直接依赖 God Client。

### 8. 无障碍

- 标准升级为 WCAG 2.2 AA。
- 基线：`docs/07_UI设计/无障碍验收基线_WCAG22.md`。
- Playwright 新增公共页面 accessible name、24px 最低目标尺寸、heading、focus-visible 检查。
- 自动通过不能被表述为“完整 WCAG 认证”。

### 9. AI

- participant AI 继续关闭。
- session 创建要求 synthetic；现在**每条消息也要求 `synthetic_data=true`**。
- 策略明确 `participant_data_allowed=false`。
- 继续去标识、只读 retrieval、无跨会话记忆、无写工具、provider/use case 服务端冻结。

# 网站后台最终验收清单

更新时间：2026-05-22

项目：`safehome1.0 / 安心陪伴 / ReadFeedback`

本清单用于网站后台 MVP 1.1 阶段收尾验收。当前清单只做验收整理，不新增后端 API，不修改数据库，不修改小程序端。

## 1. 当前后台页面状态

| 页面 | 当前状态 | 数据来源 | 验收重点 |
|---|---|---|---|
| `/dashboard` | 已完成第一版 | `GET /api/goals`、`GET /api/diaries`、`GET /api/checkins`、`GET /api/cards` | 能看到总览指标、最近记录、最近目标、已完成页面清单 |
| `/goals` | 已完成第一版 | `GET /api/goals` | 能查看目标列表和目标详情 |
| `/diaries` | 已完成第一版 | `GET /api/diaries`、`POST /api/feedback/generate`、`GET /api/cards/recommend` | 能查看记录、关键字段、生成反馈和推荐训练卡 |
| `/feedback` | 已完成第一版 | `GET /api/admin/export?type=feedback` | 能通过导出令牌查看已生成反馈结果 |
| `/checkins` | 已完成第一版 | `GET /api/checkins`、`GET /api/cards` | 能查看打卡列表、详情和训练卡标题 |
| `/reports` | 已完成第一版 | `GET /api/admin/export?type=reports` | 能查看已生成周报，不触发新周报写入 |
| `/supervision` | 已完成第一版 | `GET /api/admin/export?type=supervision` | 能查看人工督导请求列表和详情 |
| `/content/cards` | 已完成第一版 | `GET /api/cards` | 能只读查看训练卡统计、列表和详情 |
| `/content/rules` | 已完成第一版 | `content/feedback_rules.json` | 能只读查看反馈规则，不直接展示触发词和原始改写例句 |
| `/export` | 已完成第一版 | `GET /api/admin/export` | 能选择导出类型、预览 CSV、保存 CSV |
| `/integration-test` | 保留 | 现有联调页 | 页面仍可访问，不删除 |

当前没有明确暂缓的后台页面。若新增未知后台路径，应进入通用暂缓说明页，不应自动落到其他页面。

## 2. 后台导航验收

当前后台顶部导航顺序应为：

```text
总览 -> 目标管理 -> 情绪记录 -> 反馈结果 -> 打卡记录 -> 周报记录 -> 督导请求 -> 训练卡 -> 反馈规则 -> 数据导出 -> 联调测试 -> 网站首页
```

验收项：

1. 每个导航都能打开对应页面；
2. 当前页面对应导航有高亮状态；
3. `/feedback` 不再显示暂缓页；
4. `/dashboard` 的已完成页面清单包含 `/feedback`；
5. 暂缓页面清单为空或明确说明当前没有暂缓页面。

http://127.0.0.1:5173/content/rules
http://127.0.0.1:5173/export

每页通用验收项：

1. 页面不空白；
2. 页面标题正确；
3. 后台导航高亮正确；
4. 列表为空时有明确空状态；
5. 有数据时可切换详情；
6. 页面没有阻断性运行错误；
7. 页面文案保持支持性、非评判、非标签化；
8. 页面边界提示不承诺替代专业服务。

## 4. 导出令牌验收

以下页面需要本地导出令牌：

```text
/feedback
/reports
/supervision
/export
```

本地默认令牌：

```text
safehome-local-admin-token
```

验收项：

1. 不填写令牌时页面应提示填写令牌；
2. 令牌错误时应显示接口错误信息；
3. 令牌正确时可读取 CSV；
4. `/export` 可预览 CSV 前几行；
5. 导出数据使用前应先确认是否需要脱敏。

## 5. 不应触发写入的页面

以下页面应保持只读，不应主动写入数据库：

```text
/feedback
/reports
/supervision
/content/cards
/content/rules
/export
```

特别注意：

```text
/reports 不应调用 GET /api/weekly-report。
```

原因：当前 `GET /api/weekly-report` 会生成周报记录并写入数据库。网站后台 `/reports` 当前只查看已有周报导出快照。

## 9. 回滚建议

若某个网站后台页面出错：

1. 优先从 `apps/web/src/main.tsx` 隐藏对应导航入口；
2. 保留页面文件，便于排查；
3. 不删除后端接口；
4. 不改数据库；
5. 不影响小程序核心链路；
6. 在交接文档中标注该页面暂缓。

若导出页面出错：

1. 保留 `GET /api/admin/export`；
2. 隐藏 `/export` 页面入口；
3. 使用 API 文档中的 PowerShell 命令临时导出；
4. 修复后再恢复页面入口。

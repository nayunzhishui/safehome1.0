# 数据字典

最后更新时间：2026-06-04

本文档用于说明 `GET /api/admin/export` 导出的 CSV 字段。导出数据仅用于本地试点核对、研究资料整理和授权范围内分析；导出前必须确认用户授权、脱敏要求和高风险记录处理边界。

## 1. 导出前检查

```text
1. 已确认导出场景属于项目试点、研究整理或督导复核需要。
2. 已确认用户授权，尤其是 research_authorization / research_consent。
3. 已确认是否包含高风险或需复核记录。
4. 对外汇报、归档或共享前，应再次去除可识别身份信息。
5. 不把 CSV 原始数据直接外发给无授权人员。
6. 不把导出结果用于诊断、治疗、危机干预或法律判断。
7. 同步 CSV 导出默认 `limit=1000`，最大 `limit=5000`。
```

## 2. 导出类型

| type | 中文名称 | 数据来源 | 主要用途 | 脱敏说明 |
|---|---|---|---|---|
| `goals` | 目标数据 | `goals` 白名单转换 | 查看目标设定情况 | 使用 `anonymous_id`，目标和动机只导出长度 |
| `diaries` | 情绪记录 | `emotion_diaries` 白名单转换 | 查看具体情绪事件和回应线索 | 使用 `anonymous_id`，自由文本只导出长度 |
| `feedback` | 反馈结果 | `feedback_results` 白名单转换 | 查看规则反馈和推荐训练卡 | 不导出支持性反馈原文 |
| `checkins` | 练习尝试记录 | `checkins` 白名单转换 | 查看训练卡练习后的尝试情况 | 复盘只导出长度 |
| `assessments` | 测一测结果 | `assessment_results` 白名单转换 | 查看工作表/测评提交结果 | 不导出完整 answers_json/scores_json |
| `profile` | 学生画像摘要 | `student_profiles` 转换 | 查看画像摘要、风险状态和推荐任务 | 使用 `anonymous_id`，不导出自由文本原文 |
| `student_profiles` | 学生画像摘要 | `student_profiles` 转换 | 同 `profile` | 使用 `anonymous_id`，不导出自由文本原文 |
| `records` | 研究摘要 | `records` 白名单转换 | 统一研究摘要导出 | 使用 `anonymous_id`，不导出完整 data_json，高风险需二次确认 |
| `student_followups` | 学生追踪记录 | `student_profile_followups` 转换 | 查看复测、任务尝试和状态评分 | 使用 `anonymous_id`，只导出文本长度和关键词摘要 |
| `sandplay` | 沙盘表达记录 | `student_sandplay_entries` 转换 | 查看沙盘任务摘要 | 使用 `anonymous_id`，不导出完整反思原文 |
| `parent_assessments` | 家长双量表摘要 | `parent_assessment_submissions` 转换 | 查看家长报告和量表均分 | 使用匿名编号，仍可能含研究批次信息 |
| `raw_wide` | 家长原始宽表 | `parent_assessment_submissions` 转换 | 研究清洗和统计准备 | 仅导出同意研究使用的数据，输出 `participant_code_hash` |
| `long` | 家长长表 | `parent_assessment_submissions` 转换 | 统计分析长表 | 仅导出同意研究使用的数据，输出 `participant_code_hash` |
| `codebook` | 量表题项说明 | 内容库 | 理解题项、维度和反向计分 | 不含用户数据 |
| `reports` | 周报记录 | `weekly_reports` 白名单转换 | 查看周度复盘记录 | 周报建议只导出长度 |
| `supervision` | 督导请求 | `supervision_requests` 白名单转换 | 查看人工补充支持请求 | 消息、联系方式、风险提示和回复只导出长度 |
| `cards` | 训练卡内容 | `training_cards` 白名单转换 | 查看训练卡内容快照 | 只导出 ID、标题、类型、标签、版本等摘要 |

## 3. 通用字段字典

| 字段名 | 中文含义 | 数据类型 | 是否脱敏 | 是否敏感 | 研究用途 | 缺失说明 |
|---|---|---|---|---|---|---|
| `id` | 记录 ID | string | 否 | 低 | 关联同一条业务记录 | 不应为空 |
| `user_id` | 用户 ID | string | 否 | 中 | 内部接口和旧数据核对 | 默认后台 CSV 已尽量替换为 `anonymous_id` |
| `anonymous_id` | 匿名用户 ID | string | 是 | 低 | 脱敏后聚合分析 | 由 `user_id` 哈希生成或业务写入 |
| `created_at` | 创建时间 | datetime string | 否 | 低 | 时间顺序、试用活跃度 | 无时间则无法做趋势分析 |
| `updated_at` | 更新时间 | datetime string | 否 | 低 | 判断记录是否更新 | 部分表没有该字段 |
| `risk_level` | 风险等级 | enum | 不适用 | 高 | 人工关注和安全筛查 | 缺失时不能判断风险状态 |
| `requires_review` | 是否需要人工复核 | 0/1 或 boolean | 不适用 | 高 | 复核队列筛选 | 缺失时默认不能视为已安全 |
| `export_allowed` | 是否允许导出 | 0/1 | 不适用 | 中 | 控制研究导出范围 | 0 表示不应进入研究导出 |
| `data_quality` | 数据质量标记 | string | 不适用 | 中 | 判断完整、重复、修正等情况 | 缺失表示未做质量标记 |
| `research_authorization_status` | 匿名研究授权状态 | string | 不适用 | 中 | 判断画像研究授权状态 | 缺失表示未记录或未同步 |
| `consent_summary_json` | 同意状态摘要 | JSON string | 不适用 | 中 | 查看同意版本和授权状态 | 缺失表示旧数据或未记录 |

## 8. 关系试点隐私规则

```text
绘画、句子补全、开放叙事和研究备注不进入默认导出。
报告消息只发送摘要和报告 ID，不发送原文。
普通用户只能访问自己的报名、报告、任务、成长记录和已确认探索手记。
研究者访问和操作必须鉴权并写 audit_logs。
```

## 9. 高风险导出规则

```text
profile / student_profiles / records 如果包含 high 风险或需复核记录，后端会要求 confirm_high_risk=true。
该确认只表示导出人知道数据敏感，不代表可以随意外发。
导出页面和 CSV 预览不应展示高风险自由文本原文。
```

## 10. 缺失值解释

| 缺失形式 | 含义 | 建议处理 |
|---|---|---|
| 空字符串 | 用户未填写或字段不适用 | 统计前按缺失处理 |
| `null` | 数据库允许为空 | 不要强行解释为 0 |
| `[]` | 当前没有列表项 | 可解释为没有推荐/没有记录 |
| `{}` | 当前没有结构化摘要 | 需要回看来源记录或标记为缺失 |
| `empty` | 导出接口没有记录 | 表示当前筛选条件下无数据 |

报告状态统一为`pending_review`、`ready`、`confirmed`、`sent`、`updated`；小程序与Web的显示文案由`shared/contracts/relationship-ui.json`生成，不各自维护第二套映射。

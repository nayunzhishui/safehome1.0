## 1. 当前项目定位

`safehome1.0 / 安心陪伴 / ReadFeedback` 是一个面向家长的情绪管理支持系统。MVP 1.0 的核心闭环是：

目标设定 -> 情绪事件记录 -> 情绪与互动模式识别 -> 非诊断反馈 -> UP 训练卡推荐 -> 家长练习与打卡 -> 周度报告 -> 人工督导补充

当前开发策略是：小程序端与网页端并行开发，但两端必须共用同一套 Flask + SQLite 后端 API、共享字段结构和内容库。

## 6. 已知问题

1. 当前后端没有登录、鉴权和真实用户系统，默认测试用户为 `demo-parent`。
2. 当前反馈为规则匹配，不接入 AI，也不进行复杂心理评估。
3. 当前风险识别只保留规则字段和人工督导入口，尚未完成高风险危机处理流程。
4. 当前 SQLite 适合 MVP 和本地试点，不适合正式多人长期并发使用。
5. 当前 CSV 导出没有权限限制，正式部署前必须加后台鉴权。
6. 当前网页端和小程序端只有最小联调测试入口，还不是正式产品页面。
7. 小程序端本地请求 Flask 后端时，可能需要微信开发者工具关闭合法域名校验。
8. `npm run build` 会生成 `apps/web/dist`，该目录属于构建产物，不应提交。
9. `npm install` 会生成 `apps/web/node_modules`，该目录属于依赖目录，不应提交。

# SafeHome 文档导航

更新时间：2026-07-30

本页只负责导航和状态说明，不替代权威文档，不移动或删除历史资料。

## 先读顺序

1. `00_当前事实基准/项目进度统一口径.md`
2. `00_当前事实基准/当前进度交接.md`
3. `00_当前事实基准/Claude计划模式.md`
4. 当前任务在 `01_当前执行入口/` 下的唯一主计划
5. 与本次改动直接相关的技术、部署、伦理或 UI 文档

## 目录职责

| 目录 | 唯一职责 | 写入规则 |
|---|---|---|
| `00_当前事实基准` | 当前真实状态、计划执行记录和交接 | 只写增量事实；不复制整份历史 |
| `01_当前执行入口` | 尚在执行或可恢复的大任务主计划 | 一个大任务只保留一个权威入口 |
| `02_专项进度与验收` | 专项审查、验收结论和证据索引 | 结论绑定代码版本、命令和证据 |
| `03_技术真相` | API、数据库、共享契约等现行技术事实 | 字段或接口变化时同步更新 |
| `04_部署联调` | 开发联调、测试环境排障 | 不作为生产运行手册 |
| `04_部署运维` | 发布、备份恢复、外部访问和生产运行 | 不记录真实密钥或密码 |
| `05_伦理试用` | 同意、隐私、试点和人工门禁证据 | 工程完成与人工批准分开 |
| `05_内容与心理边界` | 用户文案、反馈边界和内容治理 | 保持非诊断、非标签化 |
| `06_产品规划` | 产品路线、优先级和阶段范围 | 不覆盖当前事实基准 |
| `07_UI设计` | 设计系统、页面规范和视觉验收 | 设计稿与真实实现分开记录 |
| `08_已完成整改记录` | 已完成专项的只读摘要 | 不再作为继续开发入口 |
| `09_历史归档` | 可追溯但不再生效的历史文档 | 文件头标明替代文件 |
| `10Claude协作` | Claude 交接、审查和补丁来源 | 不把外部环境结果写成当前完成 |
| `99_待确认或已删除记录` | 待核对、删除清单和保留原因 | 不作为生产事实来源 |

## 保守整理方案

当前不批量重命名、不移动权威文档。后续只在有测试和链接检查的独立任务中：

1. 把重复的任务过程记录合并成“主计划 + 证据索引”；
2. 把已被替代的部署清单移入 `09_历史归档`，并保留跳转说明；
3. 把自动生成的 HTML、快照和机器报告放到统一的可再生成目录；
4. 删除动作必须先生成引用清单并取得负责人确认。

# T38-F08 研究者证据工作台视觉审计

日期：2026-07-27

## 审计目标

- 让研究者先看到参与者议题与证据时间线，而不是总分或装饰性指标；
- 让观察、模式候选、人工假设和未知项在视觉上可区分；
- 严格区分内部记录与参与者可见草稿；
- 保持 SafeHome 米白背景、森林绿主色、圆角卡片和低刺激视觉风格。

## 本轮调整

- Web 工作台改为“记录列表—议题与证据—草稿区”的三段结构；
- 证据卡展示来源、时间、提供者、情境、权限、方法限制和关联问题；
- 人工假设区并列呈现支持依据、反证、其它可能和参与者识别度；
- 内部记录与参与者可见草稿使用独立容器、标签和说明；
- 小程序研究者仪表盘复用相同字段、筛选项和草稿保存接口；
- 无可核对依据时，界面阻止创建正式反馈草稿，不再生成占位依据。

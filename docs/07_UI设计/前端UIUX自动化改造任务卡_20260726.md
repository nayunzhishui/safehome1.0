# 前端 UI/UX 自动化改造任务卡（20260726）

面向 **Claude Code 自动化执行**。每张卡片自带：目标、影响文件、执行步骤、**自动验证命令**、**不得破坏项**。按批次串行；批内动作可并行。

## 全局铁律（所有卡片共同遵守）

- 不改后端 API、`shared` 类型、`content` 来源、小程序联调页（`pages/integration-test`、`pages/debug`）与任何核心业务链路。
- 只动样式、组件装配、路由装配、发布配置；不动业务逻辑与数据流。
- 每张卡片执行后必须跑该卡的"自动验证命令"，绿灯才算完成；红灯回滚该卡。
- 基线自检（每批开始前后各跑一次，确保无回归）：
  - 小程序：`node --check` 遍历所有 `.js`；所有 `.json` 可解析；`python backend/scripts/validate_miniprogram_assets.py`。
  - Web：`cd apps/web && npm run build && npx tsc --noEmit`。
  - 后端契约不受影响：`python -m pytest backend/tests -q`（对照本次基线数，不新增失败）。

## 批次 A：设计 token 单一化（零业务风险，先做）

### A1　建立 token 单一来源 + 生成脚本
- 目标：`shared/design/experience-tokens.json` 成为唯一真相，自动生成小程序与 Web 的变量段。
- 影响文件：新增 `scripts/gen_design_tokens.py`；改 `apps/miniprogram/app.wxss` 的 `:root/page` 变量段、`apps/web/src/styles.css` 的 `:root` 变量段（用 `/* AUTO-GEN:tokens START */ … END */` 注释锚点包裹自动区，只覆盖锚点内内容）。
- 步骤：① 读 `experience-tokens.json` 的 color/touch_target/radius；② 映射为 `--safe-*` 变量；③ 写入两个锚点区；④ 提供 `--check` 模式（生成物与现文件 diff 为空则退出 0）。
- 自动验证：`python scripts/gen_design_tokens.py --check` 退出 0；`npm run build`（web）通过；小程序 JSON/JS 静态检查通过。
- 不得破坏：变量名沿用现有 `--safe-*`；不得改变量的最终色值（除 A3 修正项）。

### A2　页面级硬编码色值 token 化
- 目标：把 40 页 wxss 中约 340 处 `#RRGGBB` 替换为最近邻 `var(--safe-*)`。
- 影响文件：`apps/miniprogram/pages/**/*.wxss`、`apps/miniprogram/components/**/*.wxss`。
- 步骤：① 写 `scripts/map_hex_to_token.py`，建立 hex→token 映射表（来自 tokens 文件）；② 精确匹配的 hex 自动替换；③ 无精确匹配的输出"待人工确认清单"，**不自动改**（避免视觉漂移）。
- 自动验证：`grep -roE '#[0-9a-fA-F]{3,6}' apps/miniprogram/pages --include=*.wxss | wc -l` 显著下降（目标：仅剩清单里的近似色）；关键页 375/430/768/1440 截图与改前比对无差异。
- 不得破坏：不改渐变/阴影中确无对应 token 的色值（进清单）；不合并语义不同但值相同的颜色。

### A3　tabBar 与 token 色值对齐
- 目标：`app.json` tabBar `#4E7C6B` 与 token `--safe-primary:#4f7c6b` 统一（大小写/值一致）。
- 影响文件：`apps/miniprogram/app.json`。
- 自动验证：字符串比对 tabBar 选中色 == tokens.primary。
- 不得破坏：tabBar 图标路径、页面顺序不变。

### A4　超小字号收敛
- 目标：把 <24rpx 的 219 处字号提到 ≥24rpx，并收敛为 3 档辅助字号 token（`--font-caption/small/body`）。
- 影响文件：`apps/miniprogram/pages/**/*.wxss`、`components/**/*.wxss`、`app.wxss`（新增 3 档字号变量）。
- 步骤：① 在 tokens 增加 3 档辅助字号；② 脚本把 10–23rpx 归一到最近的辅助档（下限 24rpx）。
- 自动验证：`grep -roE 'font-size:\s*(1[0-9]|2[0-3])rpx' apps/miniprogram/pages apps/miniprogram/components --include=*.wxss | wc -l` == 0。
- 不得破坏：不动 ≥24rpx 的字号；不改行高导致换行错位（抽查关键页截图）。

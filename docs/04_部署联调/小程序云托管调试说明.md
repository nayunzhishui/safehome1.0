# 小程序云托管调试说明

更新时间：2026-07-02

本文档用于排查微信小程序通过 `wx.cloud.callContainer` 调用后端时的连接问题，尤其是 `cloud.callContainer:fail 102002`。

## 1. 当前配置

配置来源：

```text
apps/miniprogram/services/cloudConfig.js
```

| 项 | 当前值 |
|---|---|
| 云环境 ID | `prod-d3gl35otiaa7c8d24` |
| 云托管服务名 | `flask-gh3l` |
| HTTP fallback 地址 | `https://flask-gh3l-261352-9-1436233118.sh.run.tcloudbase.com` |
| 本地调试地址 | `http://127.0.0.1:5000` |
| debug 页面 | `pages/debug/index` |

`app.js` 和 `services/api.js` 不再直接写死这些值，而是通过 `getCloudConfig()` 读取。

配置读取顺序：

```text
1. 默认配置：cloudConfig.js；
2. 小程序 extConfig：safehomeCloud 或 cloudConfig；
3. wx storage：safehome_cloud_config；
4. createSafeHomeApi(options) 传入的临时覆盖。
```

## 2. 打开 debug 页面

在微信开发者工具中打开页面：

```text
pages/debug/index
```

页面会显示：

- 云环境 ID；
- 云托管服务名；
- HTTP 基础地址；
- 当前默认匿名 `user_id`；
- 最近一次错误 code；
- 最近一次错误 message；
- 最近一次错误 debug 信息。

## 3. 调试按钮

依次点击：

1. 如需本地后端，先点击“切换本地 5000”；
2. 如需云托管后端，点击“切回云托管”；
3. 测试 `healthz`；
4. 如后端已发布任务九代码，测试公网 `/readyz`；
5. 测试 `assessments`；
6. 测试 `risk/check`；
7. 测试 `profile` 最小请求。

如果 `healthz` 失败，优先检查 CloudBase 环境、服务名和服务运行状态。

如果 `healthz` 成功但 `/readyz` 返回 404，说明云端仍是旧版本，尚未发布包含任务九 `/readyz` 的代码。

## 3A. 本地 5000 调试模式

当微信开发者工具能看到页面样式变化，但量表列表仍显示旧版 `worksheet_*` 时，通常说明：

```text
小程序前端使用了本地代码；
量表列表仍来自云托管旧后端。
```

可临时切换到本地 Flask：

```powershell
$env:PORT='5000'
$env:FLASK_DEBUG='0'
$env:PYTHONIOENCODING='utf-8'
D:\python\anada\python.exe backend\app.py
```

然后在微信开发者工具中打开：

```text
pages/debug/index
```

点击：

```text
切换本地 5000 -> 测试 assessments
```

如果测试通过，再回到“测一测”页面。此时 `/api/assessments` 应返回本地 `content/assessment_worksheets.json` 中的量表。

注意：

```text
1. 微信开发者工具需要允许本地 HTTP 调试，必要时勾选“不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书”。
2. 本地 5000 只适合开发者工具；真机预览时 127.0.0.1 指向手机自身，不是电脑。
3. 发布前应点击“切回云托管”，或清空 wx storage 中的 safehome_cloud_config。
```

## 4. 102002 排查

出现 `cloud.callContainer:fail 102002` 时，请截图记录：

```text
env
service
path
method
errCode
errMsg
```

排查顺序：

1. 云环境 ID 是否和 CloudBase 控制台一致；
2. 云托管服务名是否为 `flask-gh3l`；
3. 云托管服务是否已启动；
4. 后端 `/healthz` 是否正常；
5. 后端 `/readyz` 是否存在且返回 200；
6. 后端 `/healthz/deep` 是否提示数据库或内容库缺失；
7. 小程序调用路径是否以 `/api`、`/healthz` 或 `/readyz` 开头。

## 5. 边界

debug 页面不加入 tabBar，不作为正式用户页面。它只用于开发联调和试点前排错。

## 6. 微信与手机号登录联调

微信一键登录通过 `wx.cloud.callContainer` 调用时，确认公网流量不能绕过云托管网关后，在云托管服务环境变量中显式设置 `TRUST_CLOUDBASE_IDENTITY_HEADERS=1`。后端才会读取云托管注入的 `X-WX-OPENID` 和固定值 `X-WX-SOURCE=wx-cloudbase`；默认关闭此路径。非云托管部署需要在服务端环境变量配置 `WECHAT_APPID`、`WECHAT_SECRET`。

手机号快捷登录还需要在微信云托管控制台完成一次外部配置：

```text
服务管理 -> 云调用/开放接口服务 -> 开启
允许接口：/wxa/business/getuserphonenumber
```

容器会周期性获得微信令牌，默认路径：

```text
/.tencentcloudbase/wx/cloudbase_access_token
```

验收顺序：

```text
1. 发布包含 /api/auth/phone-login 的新后端版本。
2. 清缓存并重新编译小程序。
3. 点击“微信一键登录”，确认不再显示环境变量名称。
4. 退出后点击“手机号快捷登录”，同意授权。
5. 确认登录成功；数据库users只出现phone_hash、phone_verified_at和phone_source，不出现完整手机号。
6. 再次使用同一手机号登录，确认返回同一user id。
```

若手机号登录返回 `wechat_phone_config_missing`，先检查开放接口服务和令牌文件；返回 `wechat_phone_exchange_failed` 时重新点击按钮获取新 code，不要重复使用旧 code。

## 7. 微信订阅练习提醒上线步骤

外部平台路径：

```text
微信公众平台 -> 小程序 -> 功能 -> 订阅消息 -> 公共模板库
```

选择与日程、待办或练习提醒语义相符且措辞中性的模板并提交审核。不要申请医疗诊断、疗效承诺或危机干预类模板。审核通过后复制模板 ID 和实际字段名，再配置云托管环境变量：

```text
WECHAT_APPID=真实小程序AppID
WECHAT_SECRET=真实小程序Secret
WECHAT_TRAINING_DUE_TEMPLATE_ID=审核通过的模板ID
WECHAT_TRAINING_DUE_TEMPLATE_FIELDS={"审核字段1":"title","审核字段2":"time","审核字段3":"note"}
WECHAT_TRAINING_DUE_PAGE=pages/personalized-plan/index
WECHAT_SUBSCRIBE_MODE=once
NOTIFICATION_SCHEDULER_TOKEN=高强度随机值
WECHAT_SUBSCRIBE_SEND_ENABLED=0
```

先以调度令牌调用 `POST /api/notifications/run-due`，请求体 `{ "dry_run": true }`。确认候选数量符合预期后，再在受控测试版本中把发送开关改为 `1`。定时任务建议每天北京时间固定时段调用一次；不要在用户打开首页时自动弹授权框。

真机验收至少覆盖：

1. 保存进行中的练习节奏后，参与者主动点击“开启一次微信提醒”；
2. 同意后，演练任务只计入到期且有 OpenID 的参与者；
3. 拒绝或禁止后仍能正常浏览、练习和打卡；
4. 一次性授权成功发送后显示“上次授权已使用”；
5. 同一用户同一天重复执行定时任务不重复发送；
6. 普通网络失败可重试且不超过 3 次；微信返回未授权时停止重试；
7. 消息点击后进入 `pages/personalized-plan/index`；
8. 正式环境确认 `miniprogram_state=formal`，测试环境保持 `trial`。

当前代码已完成授权、偏好、调度、幂等、失败状态和默认关闭保护；模板申请、平台审核与真机接收必须由有权限的小程序管理员完成。

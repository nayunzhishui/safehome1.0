# 前端联调说明

本文档记录小程序端与网页端并行联调的最小路径。当前不开发复杂页面，只先建立统一 API 调用层。

## 1. 启动后端

```powershell
cd D:\codex\workspace\safehome1.0\backend
pip install -r requirements.txt
python seed_data\seed.py
python app.py
```

健康检查：

```text
http://127.0.0.1:5000/healthz
```

## 2. 网页端 API client

文件：

```text
apps/web/src/services/safehomeApi.ts
```

最小联调入口：

```text
apps/web/src/pages/IntegrationSmokeTest.tsx
```

运行方式：

```powershell
cd D:\codex\workspace\safehome1.0\apps\web
npm install
npm run dev
```

打开：

```text
http://127.0.0.1:5173
```

默认后端地址：

```text
http://127.0.0.1:5000
```

示例：

```ts
import { safeHomeApi } from "./services/safehomeApi";

const diary = await safeHomeApi.createDiary({
  scene: "作业拖延",
  event_description: "孩子一直不开始写作业，我忍不住催了很多次。",
  parent_emotion: "着急",
  parent_emotion_intensity: 8,
  automatic_thought: "他就是故意拖。",
  behavior: "反复催促。",
});

const feedback = await safeHomeApi.generateFeedback({ diary_id: diary.id });
const cards = await safeHomeApi.recommendCards({ tags: feedback.tags });
```

## 3. 小程序端请求封装

文件：

```text
apps/miniprogram/services/api.js
```

最小联调入口：

```text
apps/miniprogram/pages/integration-test/index
```

使用微信开发者工具打开：

```text
D:\codex\workspace\safehome1.0\apps\miniprogram
```

示例：

```js
const { createSafeHomeApi } = require("../../services/api");

const api = createSafeHomeApi({
  baseUrl: "http://127.0.0.1:5000",
});

api.createDiary({
  scene: "作业拖延",
  event_description: "孩子一直不开始写作业，我忍不住催了很多次。",
  parent_emotion: "着急",
  parent_emotion_intensity: 8,
  automatic_thought: "他就是故意拖。",
  behavior: "反复催促。",
}).then((diary) => {
  return api.generateFeedback({ diary_id: diary.id });
}).then((feedback) => {
  return api.recommendCards({ tags: feedback.tags });
});
```

## 4. 微信开发者工具注意事项

本地联调时，微信开发者工具可能拦截 `http://127.0.0.1:5000` 请求。

开发阶段可在微信开发者工具中开启：

```text
详情 -> 本地设置 -> 不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书
```

正式发布前不能依赖这个设置，必须配置 HTTPS 后端域名。

## 5. 最小联调顺序

1. `GET /healthz`
2. `POST /api/diaries`
3. `POST /api/feedback/generate`
4. `GET /api/cards/recommend`

这四步跑通后，再进入真实页面开发。

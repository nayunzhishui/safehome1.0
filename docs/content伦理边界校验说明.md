# content 伦理边界校验说明

更新时间：2026-06-05

`backend/scripts/validate_content.py` 现在同时做两类检查：

1. 结构检查：按 `content/schemas/*.schema.json` 检查必填字段、列表字段和最小条目数。
2. 伦理边界检查：检查重复 ID、推荐训练卡 ID 是否存在、high 风险规则是否错误推荐普通训练卡、训练卡是否写明高风险/危机/安全边界、风险词库 high 处理是否禁止普通训练卡、禁用语和非诊断边界说明。

允许出现“不构成诊断”“不替代心理咨询/危机干预”等边界表述。脚本不会把这类合法说明当成违规。

脚本只做自动预检，不能替代心理学人工审核。候选内容不得因通过脚本而标记为正式临床内容。

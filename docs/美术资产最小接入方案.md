# 美术资产最小接入方案

创建日期：2026-05-23

项目：`safehome1.0 / 安心陪伴 / ReadFeedback`

本文档用于规划下一阶段最小美术资产接入。当前只做方案，不生成图片，不修改页面代码，不修改后端 API，不修改数据库。

## 1. 目标

当前小程序已经完成主要页面和核心链路视觉统一，但多数页面仍使用 CSS 轻量图形或纯卡片展示。

下一步美术资产接入目标是：

1. 提升首页、教育热榜、反馈页、课程页、周报页的温暖感和专业感；
2. 保持非医疗化、非诊断化；
3. 不引入复杂依赖；
4. 不影响现有页面路径和业务逻辑；
5. 不新增后端 API；
6. 不修改数据库；
7. 不替换现有核心流程。

## 2. 资产风格

统一风格：

```text
扁平插画
轻拟物但不过度
柔和绿色、暖橙、浅蓝
浅米白背景
人物表情温和
家庭关系积极但不完美化
大留白
适合 30-45 岁家长
```

禁止风格：

```text

诊断风格

黑暗压抑
恐慌表情
过度幼稚卡通

```

## 5. 命名规则

文件命名使用英文小写和短横线：

```text
home-family-care.png
diary-reflection.png
feedback-support.png
hot-topics-family-talk.png
course-cover-emotion.png
weekly-growth.png
supervision-guide.png
empty-gentle-note.png
```

不要使用：

```text
中文文件名
空格
临时截图名
微信图片默认名
```

原因：

1. 小程序资源路径更稳定；
2. 后续 Git diff 更清楚；
3. 不容易出现编码路径问题。

## 6. AI 图片生成提示词

### 6.1 首页亲子陪伴插画

```text
为一个面向30-45岁家长的亲子情绪支持微信小程序生成首页欢迎插画。画面是家长和孩子在温暖的客厅或书桌旁安静交流，旁边有绿植、书本、阳光、小房子或成长树元素。整体温暖、柔和、专业、可信，浅米白背景，柔和绿色、暖橙色、浅蓝色点缀，扁平插画，轻拟物但不过度，大留白，人物表情平静真实，适合放在移动端首页顶部卡片中。
```

负向提示：

```text
不要医院风格，不要诊断风格，不要药物、病床、听诊器、红十字，不要黑暗压抑，不要恐慌表情，不要过度幼稚卡通，不要商业营销海报感。
```

### 6.2 情绪记录插画

```text
为亲子情绪记录页面生成温和插画。画面表现一位家长在安静记录当天亲子互动片段，旁边有简洁的情绪小符号、书本和绿植。氛围是自我观察、轻松记录、没有压力。浅米白背景，柔和绿色和暖橙色点缀，扁平插画，高质量 UI 插画，适合微信小程序顶部卡片。
```

### 6.3 反馈页支持插画

```text
为非诊断反馈页面生成支持性插画。画面表现家长看到一张温和反馈卡，旁边有对话气泡、绿植和柔和光线。重点表达“这不是评价谁对谁错，而是帮助找到下一步小练习”。整体专业、可信、温暖，浅米白、柔和绿色、暖橙色、浅蓝色配色，扁平化 UI 插画。
```

### 6.4 教育热榜案例插画

```text
为家庭教育案例库页面生成插画。画面表现几个温和的亲子互动小场景，例如作业沟通、手机边界、冲突后重新连接，使用分区小卡片的构图。整体不是娱乐热榜，不是营销海报，而是专业、温暖、可信的家庭教育案例库视觉。浅米白背景，柔和绿色和暖橙色点缀。
```

### 6.5 课程页封面通用图

```text
为家长心理健康教育课程生成课程封面插画。画面表现家长学习情绪管理与亲子沟通方法，包含书本、课程卡片、绿植、柔和阳光和家庭成长元素。风格温暖、专业、系统，但不要商业化，不要像短视频平台封面。适合移动端课程卡片封面。
```

### 6.6 周报成长插画

```text
为一周亲子陪伴复盘页面生成成长插画。画面包含温和的成长曲线、日历、几张小记录卡、绿植或成长树，表达“看见一周中的小变化”。不要评分感，不要考试感，不要诊断报告感。浅米白背景，柔和绿色主色，暖橙和浅蓝点缀。
```

### 6.7 人工督导插画

```text
为人工督导补充反馈页面生成插画。画面表现一位专业老师或督导人员拿着记录板，温和地阅读家长提交的记录，旁边有对话气泡和绿植。表达“补充理解和练习建议”，不表达治疗、诊断或实时危机处理。风格温暖、专业、可信，扁平 UI 插画。
```

### 6.8 空状态插画

```text
为亲子情绪支持小程序生成空状态插画。画面是一张空白记录卡、绿植、书本和柔和阳光，表达“可以从一次小记录开始”。温暖、简洁、低压力，浅米白背景，柔和绿色和暖橙点缀，适合用于暂无记录、暂无周报、暂无训练记录等页面。
```

## 7. 接入顺序

建议分三步接入，不一次性大改。

### 第一步：只接入首页和教育热榜

涉及页面：

```text
apps/miniprogram/pages/home/index.*
apps/miniprogram/pages/hot-topics/index.*
```

原因：

1. 用户第一眼看到；
2. 当前已有 CSS 轻量图形，替换风险较低；
3. 不影响核心 API。

### 第二步：接入反馈页和周报页

涉及页面：

```text
apps/miniprogram/pages/feedback-result/index.*
apps/miniprogram/pages/weekly-report/index.*
```

原因：

1. 反馈页是产品核心价值；
2. 周报页需要降低“报告/评分”的感觉；
3. 插画可帮助解释“非诊断复盘”。

### 第三步：接入课程页和督导页

涉及页面：

```text
apps/miniprogram/pages/course/index.*
apps/miniprogram/pages/supervision/index.*
```

原因：

1. 课程页目前仍是 mock；
2. 督导页需保持边界清楚；
3. 可等前两步视觉稳定后再做。

## 8. 接入前检查

每次接入插画前必须确认：

1. 图片文件大小适合小程序；
2. 文件名为英文小写短横线；
3. 不包含医疗、诊断或危机承诺元素；
4. 不遮挡文本；
5. 移动端显示不拥挤；
6. 不删除 CSS 兜底样式；
7. 不修改后端 API；
8. 不修改数据库；
9. 不删除 `pages/integration-test/index`。

## 9. 回滚方式

如果插画显示异常：

1. 从页面中移除图片引用；
2. 保留原 CSS 色块或卡片；
3. 不删除页面；
4. 不改接口；
5. 不改数据库；
6. 在交接文档中记录该资产暂缓。

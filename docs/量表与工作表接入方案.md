# 量表与工作表接入方案

创建日期：2026-05-23

本文档记录 `工作表及示例` 目录中的 PDF 工作表如何接入小程序“测一测”板块。

进度口径：当前已实现的是测一测内容库、测评列表/详情/结果保存能力；学生支持性画像测评仍处于规划和 P0 内容准备阶段。最新状态见 `docs/项目进度统一口径.md`。

## 1. 当前决策

本轮按用户确认执行：

1. 量表和工作表全部纳入“测一测”；
2. 用户端第一版直接展示原文标题和原工作表结构；
3. 量表填写数据保存到后端；
4. 允许新增数据库表和新增 API；
5. 结果页只做维度记录和支持性提示，不生成诊断结论。

4. 行为与练习类；

## 4. 统一边界提示

小程序页面必须固定展示：

```text
本内容用于自我观察和练习记录，不用于诊断，不替代心理咨询、医学诊断、危机干预或法律判断。如你或家人正在经历明显痛苦或现实风险，请及时寻求现实支持和专业帮助。
```

即使原文包含“治疗、焦虑、抑郁、暴露”等词，也不在结果页生成疾病判断。

## 5. 数据保存

新增数据库表：

```text
assessment_results
```

保存：

1. 用户 ID；
2. 工作表 ID；
3. 工作表标题；
4. 分类；
5. 答案 JSON；
6. 分数 JSON；
7. 总分；
8. 支持性结果摘要；
9. 创建时间。

第一版不采集姓名、手机号、身份证等强身份信息。

## 6. API

新增接口：

```text
GET /api/assessments
GET /api/assessments/<worksheet_id>
POST /api/assessment-results
GET /api/assessment-results
GET /api/admin/export?type=assessments
```

接口只负责返回工作表内容和保存结果，不做诊断计算。

## 9. 回滚方式

如果测一测接入出现问题：

1. 先隐藏 `assessment` 页面入口；
2. 保留后端表和接口；
3. 不删除情绪记录、反馈、训练卡、打卡、周报、督导核心链路；
4. 不删除 `pages/integration-test/index`。

## 10. 后续扩展：学生支持性画像测评（规划）

本节根据夏老师“0版网页治疗性评估原型”“心理测评数据分析”“心理干预全流程”资料整理，仅作为后续规划。当前小程序“测一测”尚未实现学生画像生成。

### 10.1 定位

学生画像测评不是新增诊断量表，而是把 0版网页的评估反馈能力接入安心家：

```text
填写量表/文本 -> 生成阶段性画像 -> 给出支持性解释 -> 推荐一个小任务 -> 进入训练/打卡/复测
```

前端文案建议使用：

- `学生支持性画像`
- `阶段性压力反应画像`
- `压力警觉型画像`

避免使用：

- `人格`
- `诊断`
- `异常`
- `障碍`
- `病理`

### 10.2 最小输入字段

后续可在 `content/assessment_worksheets.json` 中增加一个画像类条目，最小字段包括：

| 字段 | 类型 | 说明 |
|---|---|---|
| `test_anxiety` | scale | 考试焦虑相关分数 |
| `iu_score` | scale | 不确定性不耐受相关分数 |
| `f_score` | scale | 情绪调节灵活性或恐惧倾向相关分数 |
| `self_compassion` | scale | 自我同情/自我支持相关分数 |
| `free_text` | text | 学生自由文本，仅作辅助线索 |

### 10.3 结果页最小内容

`assessment-result` 或后续画像结果页应展示：

1. 画像名称；
2. 置信度；
3. 关键维度说明；
4. 优势提示；
5. 一个推荐任务；
6. 推荐训练卡；
7. 非诊断边界提示；
8. 人工复核入口。

### 10.4 与训练卡的关系

画像结果不应停留在“评价用户”，必须进入可执行练习：

- 压力警觉型：推荐情绪命名、三秒暂停、自我支持或沙盘表达任务；
- 回避倾向：推荐小步行动、接纳不确定性或认知灵活性训练；
- 自我支持不足：推荐自我关怀、资源识别和优势回顾训练。

### 10.5 技术实现建议

后续实现顺序：

1. 在内容库中新增学生画像测评条目；
2. 新增 `POST /api/profile`；
3. 画像结果先复用 `assessment_results` 保存；
4. 后续新增 `profile_results` 表；
5. 后台导出增加 `type=profile`；
6. 规则内容放入 `content/student_profile_rules.json`。

### 10.6 伦理边界

- 自由文本只用于关键词和压力线索，不用于自动诊断；
- 画像名称必须是阶段性描述，不是人格定性；
- 高风险文本不生成普通训练建议，应进入人工复核；
- 沙盘表达只作为表达媒介和访谈线索，不自动解释潜意识。

## 6. 文档阅读规则

后续阅读 Markdown 时按以下规则判断：

1. `docs/项目进度统一口径.md`：当前统一状态。
2. `docs/当前进度交接.md`：当前交接和下一步。
3. `AGENTS.md`：长期开发规则。
4. `docs/开发日志.md`：历史记录，只能按时间顺序理解，旧章节可能已被后续章节覆盖。
5. `docs/API接口文档.md`：真实 API 与规划 API 的边界。
6. `docs/数据库字段说明.md`：真实表与规划表的边界。
7. `docs/0版网页整合逐步开发任务清单.md`：学生画像模块的执行清单。

历史规划类文档如果写着“需要建立”“建议新增”，不代表当前仍未做；必须回到本文档确认最新状态。

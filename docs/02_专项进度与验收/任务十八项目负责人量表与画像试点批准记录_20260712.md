# 任务十八项目负责人量表与画像试点批准记录

记录日期：2026-07-12

## 1. 批准来源

项目负责人在当前 Codex 任务中明确表示：批准现有量表的项目内试点使用，批准三个项目的准入，并要求将阶段汇报中 2.2 节列出的模型与画像标记为审核通过和开放。

本文件只记录项目负责人的产品与试点决策，不冒充第三方版权许可、独立心理专家意见、研究负责人签字或伦理审查批件。

## 2. 自动执行范围

1. 已具备完整 worksheet、题项、选项和计分链路的量表，状态更新为 `pilot_approved` 并开放试点入口。
2. 画像模型完成量表绑定、解释审批状态和产物哈希更新；低置信度、离群、数据不足、高风险仍由既有门禁阻断。
3. HPLP 版本冲突按项目负责人指定处理：使用牛至旭资料中的 40 题版本及其模型；高鸣聪 HPLP 模型仅保留为历史对照，不参与运行时自动匹配。
4. 仅存在目录元数据、尚无完整 worksheet 的量表不因批准而伪造技术链，继续保持不可填写状态。
5. 三个项目的项目负责人准入批准已记录；研究、心理、伦理三方独立证据仍按系统治理规则单独归档。

## 3. 使用边界

所有量表和画像结果只用于支持性测评、阶段性观察、自我了解线索和训练建议，不构成诊断、筛查结论、固定人格标签或医疗建议。

## 2. 设计判断

- 对象：需要低压力记录、练习和查看人工反馈的参与者。
- 单一任务：让参与者快速判断“当前可以做什么”或“出错后如何恢复”。
- 视觉：沿用低饱和灰绿、米灰背景、细边线和轻量左侧状态轨；不增加渐变装饰或诊断感图标。
- 识别特征：圆形步骤标记只用于真实主旅程序号，状态颜色只说明当前流程，不表示好坏或疗效。
- 文案：空态给出可选择的下一步；错误明确可重试；不使用治愈、改善分数、人格或诊断表达。

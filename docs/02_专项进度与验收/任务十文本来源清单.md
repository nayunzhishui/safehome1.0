# 任务十文本来源清单

## 1. 使用原则

本清单用于任务十 T10-15 的离线文本分析。第一版只做脱敏、聚合、可解释分析，不输出用户原始自由文本，不做诊断、筛查、临床风险预测或个体标签。

## 2. 当前纳入来源

| 数据表 | 字段 | 文本类型 | 可用于情感计算 | 可用于共现网络 | 说明 |
|---|---|---|---|---|---|
| `emotion_diaries` | `event_description` | 用户填写 | 是 | 是 | 亲子互动事件描述，可提取人物、场景、情绪、行为共现。 |
| `emotion_diaries` | `automatic_thought` | 用户填写 | 是 | 是 | 自动想法，可用于情绪关键词和想法线索。 |
| `emotion_diaries` | `behavior` | 用户填写 | 是 | 是 | 行为反应，可用于互动行为节点。 |
| `emotion_diaries` | `raw_text` | 用户填写 | 是 | 是 | 原始记录文本，只做本地读取和聚合，不导出原文。 |
| `feedback_results` | `supportive_feedback` | 系统生成 | 是 | 否 | 可用于检查系统反馈语气，不用于用户网络关系判断。 |
| `supervision_requests` | `message` | 用户填写 | 是 | 否 | 人工督导请求文本，敏感度较高，第一版只做聚合。 |
| `supervision_requests` | `reply` | 督导回复 | 是 | 否 | 用于后续质控，不用于用户画像判断。 |
| `checkins` | `reflection` | 用户填写 | 是 | 否 | 训练后反思，可用于练习后情绪变化线索。 |
| `emotion_thermometer` | `brief_text` | 用户填写 | 是 | 是 | 简短事件记录，可与温度计强度对应。 |

## 3. 当前输出

离线脚本：

```text
analysis/text_analysis/analyze_text_sources.py
```

默认输出：

```text
outputs/text_analysis/text_analysis_summary.json
```

输出内容：

```text
1. 文本来源计数；
2. 情绪关键词聚合；
3. 情绪类别聚合；
4. 强度词线索分；
5. 人物、场景、行为节点；
6. 节点共现边；
7. boundary_notice；
8. raw_text_included=false。
```

## 4. 明确不做

```text
1. 不输出原始自由文本。
2. 不输出联系人、电话、学校、地址等可识别信息。
3. 不做临床诊断、筛查或风险预测。
4. 不在普通用户端展示复杂图谱。
5. 不把文本分析结果作为自动治疗建议。
```

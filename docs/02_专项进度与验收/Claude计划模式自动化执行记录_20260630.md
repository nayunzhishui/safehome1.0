## 7. Error loop 记录

```text
1. 初次接入 sync_assessment_worksheets 时，sync_training_cards 的 SQLite else 分支被挤到新函数末尾，导致 SyntaxError。已把训练卡同步和量表同步拆回两个独立函数，重新编译通过。
2. init_db 自动同步量表后，导入脚本首次运行不再 created>0，而是 skipped=27。已把测试改为验证幂等统计和核心量表落库。
3. 旧 healthz 测试仍期待 schema 版本 2026_06_04_001。已更新为 2026_07_01_001，并补 worksheets_sync_ok 断言。
4. 一个旧测试故意缺少 assessment_worksheets.json，应用启动时同步量表报 FileNotFoundError。已改为量表文件缺失时跳过同步，让具体 API 返回内容缺失错误。
```

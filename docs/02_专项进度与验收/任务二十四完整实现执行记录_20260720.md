1. 临时展示越权仍会影响Web页面级正式E2E，因此不把Web展示结果作为权限通过证据；权限结论只来自后端角色矩阵与接口测试。

3. 缓存和搜索索引当前架构不存在参与者级独立数据面，预览明确返回`not_present_in_current_architecture`，没有虚构删除动作。
4. 旧备份保留期限仍待人工确认；工程提供墓碑和恢复只读验证，不能自动改写历史备份。

## 回滚

1. 立即回滚：保持`PRIVACY_EXECUTION_ENABLED=0`、`PRIVACY_RETENTION_POLICY_APPROVED=0`、`PRIVACY_PRODUCTION_EXECUTION_ENABLED=0`。
2. 代码回滚：回退本任务提交；数据库新增表/列保留，不执行`DROP`，避免丢失证明。
3. 执行中异常：同一事务整笔回滚，申请保持`processing`，不留下伪完成流水。
4. 恢复库异常：停止服务和研究导出，运行墓碑验证；出现计数时交由管理员按证明包人工处置。

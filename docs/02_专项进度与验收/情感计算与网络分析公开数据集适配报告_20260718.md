# 情感计算与网络分析公开数据集适配报告

检索日期：2026-07-18

## 1. 结论

项目已有 `analysis/text_analysis/` 离线情感计算、语义共现网络和家庭拓扑审计，不需要重新建立一套算法。下一步应做公开数据基准、中文域内小型金标准和授权登记。

当前没有发现同时满足“中文、亲子/关系事件、纵向记录、清晰可复用许可、情绪与反射弧标注”的公开训练集。公开数据可以用于方法验证或预训练对照，不能直接证明对本项目参与者有效。

网络分析方面，NetworkX 的中心性、社区和共现统计并不需要专门训练集。SNAP 等公开图只能验证算法性能和实现正确性，不能作为家庭关系解释的训练依据。

## 2. 候选数据集

## 3. 推荐优先级

### A 级：可以先登记并做离线评估

1. CPED：最接近中文对话情绪，但仅做标签/上下文基准，先审内容权利。
2. GoEmotions：用来完善情绪类别映射和跨域失败分析，不直接训练中文正式模型。
3. SNAP 小型图：只用于 NetworkX 算法和性能测试。

### B 级：授权确认后再考虑

1. SMP2020-EWECT：适合中文短文本，但需要明确数据复用许可。
2. CH-SIMS：项目未来确有音视频研究且重新取得同意时再评估；当前不引入。
3. EmpatheticDialogues：只做回答质量对照，不作为心理咨询话术金标准。

### 不建议

- 来源不明的 Kaggle“心理咨询对话”合集；
- 抓取社交平台、咨询网站或私人聊天记录；
- 用影视对白的人格标签推断真实参与者人格；
- 用公开社交网络训练家庭关系质量、风险或诊断模型；
- 未经重新授权把现有参与者原文用于模型训练。

## 4. 项目适配路线

1. 建立数据登记表：URL、版本、论文、许可、内容权利、允许用途、哈希和删除方式。
2. 建立标签映射：公开数据标签映射到情绪类别、效价、唤醒和反射弧；不等值项保留未映射。
3. 先测当前规则：覆盖率、宏平均 F1、混淆矩阵、否定/程度/转折和校准，不先训练深度模型。
4. 建立 200—500 条合成中文事件金标准，两名标注者独立标注并计算一致性。
5. 只有公开基准和中文金标准都证明有稳定增益，才评估一个离线候选模型；仍不得自动进入参与者反馈。
6. 网络分析使用合成图验证数学正确性，项目真实数据只做经授权、脱敏、最小支持度抑制后的聚合研究。

## 6. 限制

本次为公开网页初筛，不是法律意见，也没有替项目取得数据授权。数据集主页、代码仓库许可与原始文本/影视内容权利可能不同；实际下载、训练或发布前必须逐项复核并保存许可证快照。

## 7. 更严格的模型开发顺序

不得从“找到公开数据”直接跳到“训练正式模型”。建议顺序：

1. 冻结当前规则 v3 作为基线，保存词典哈希、参数和测试结果。
2. 建立公开数据标签映射，无法等值的标签保留 unmapped，不强行合并。
3. 在公开数据上只报告覆盖率、宏平均F1、每类召回、混淆矩阵和置信区间。
4. 建立中文合成金标准，重点覆盖否定、程度、转折、反问、讽刺、混合情绪、亲子称谓和行为—情绪错配。
5. 由两名标注者独立标注；报告一致性和分歧，不把模型自动标签当金标准。
6. 只有候选方法同时改善中文域内指标、校准和严重错误，才进入研究者只读比较。
7. 任何模型都不得直接替代独立风险规则、人工队列或参与者共同核对。

## 8. 网络分析方法门禁

语义网络的结果高度依赖节点定义、共现窗口、最小支持度、边权和距离转换，因此必须做敏感性分析：

- 句子、字段和单次记录三种窗口比较；
- minimum_support 至少比较多个预设值；
- 原始共现、文档频率和标准化边权分别报告；
- 中心性使用与边权含义一致的距离；
- 社区算法记录随机种子和不稳定性；
- 时间窗变化只作描述，不自动解释为关系改善或恶化；
- 小样本节点和边继续抑制，不因图形美观降低隐私阈值。

公开SNAP图只能验证计算性能、连通性、中心性和社区实现。项目语义共现网络不是真实社会关系网络；`family_links`拓扑只做授权绑定完整性审计，不评价关系质量。

## 9. 数据集卡最小字段

每个候选数据必须登记：

```text
dataset_id / version / source_url / paper
license_snapshot / content_rights_review
language / domain / population / sampling
labels / annotation_process / agreement
train_dev_test_split / duplicate_policy
sensitive_content / known_biases
allowed_uses / prohibited_uses
download_hash / local_location / deletion_method
project_label_mapping / domain_gap
```

许可、内容权利、标注过程或允许用途任一不清时，状态保持 `metadata_only`。

```text
   - 新增 content/programs.json。

   - 新增 analysis/profiling/affective_computing_prototype.py。
   - 新增 analysis/profiling/social_network_prototype.py。
   - 输出脱敏聚合 JSON，不包含原始文本、联系方式或真实身份。

7. 稳定性与共享层
   - MySQL 连接增加 connect/read/write timeout 与 ping/reconnect。
   - 动态 SQL 标识符位置补充内部 schema/正则校验说明。
   - shared/constants/api.ts 新增任务八端点与 API_ERROR_CODES。
   - shared/types/api.ts 新增温度计、训练计划、项目测试类型。
```

# 任务二十二 P1 与 P3 执行记录

日期：2026-07-18

## 范围

本轮按负责人要求跳过 P0，只完成：匿名试用数据认领、研究运营与通知监控、Web 性能和局部架构优化。临时展示越权保持原状。

## 已实现

1. 登录设备的匿名 ID 只登记为待认领候选，不自动迁移数据。
2. 参与者登录后可预览各模块数量，并明确选择“确认合并”或“暂不处理”。
3. 合并在单一数据库事务内完成，按 `claim_id + target_user_id` 隔离，重复请求幂等；保留认领流水和审计，不返回试用期原文。
4. 研究运营接口按角色统计提醒授权、投递、失败代码、阶段反馈、人工支持和风险复核积压；研究者仅统计分配给自己的参与者。
5. Web 研究工作台新增“提醒与人工工作水位”，只展示脱敏数量和错误代码。
6. ECharts 改为只注册雷达图、散点图及所需组件；研究总览依赖首批列表的详情请求改为并行。

## 关键路径

- 小程序：`我的 -> 把本机试用记录放进当前账号 -> 确认合并/暂不处理`
- Web：`/login -> 登录成功 -> 试用记录确认 -> 进入账号页面`
- 研究运营：Web `/dashboard` 的“提醒与人工工作水位”
- API：`GET /api/auth/data-claim-preview`、`POST /api/auth/data-claim`、`GET /api/research/operations`

## 安全与伦理边界

- 不允许管理/研究角色认领匿名参与者数据。
- 预览和运营接口不返回自由文本、联系方式、OpenID、模板密钥或错误原文。
- 已认领流水不做自动反向迁移；必要时按审计记录由管理员受控处理。
- 本轮没有完成 P0 人工验收、微信真机、CloudBase/MySQL 或正式发布。

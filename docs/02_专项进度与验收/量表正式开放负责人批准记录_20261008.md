## 4. 回滚方式

- 代码与内容：回退本次提交即可恢复到 `2026.10-scale-review-corrections-v3` 与 `2026.10-cards-v2`。
- 生产数据库：内容同步每次应用前都会整表备份，可用 `/api/admin/content-sync/restore` 按备份恢复。
- 只撤销生产开放、不回退内容：清空治理文件中的 `production_manifest.worksheet_ids`，生产环境即不再向用户列出量表（门禁按清单判断，失败即关闭）。

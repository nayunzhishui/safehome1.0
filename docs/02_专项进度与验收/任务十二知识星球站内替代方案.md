# 任务十二知识星球站内替代方案

更新时间：2026-07-10

## 目标

不依赖知识星球 API、不向外部平台传输测评、叙事、绘画或研究备注，也能完成“内容继续—任务练习—提醒消息—报告反馈—人工支持”的MVP闭环。

## 能力映射

| 外部平台设想 | 站内替代 | 当前基础 | 下一步最小增强 |
|---|---|---|---|
| 账号衔接 | 正式账号、角色和家庭绑定 | `users`、账号登录、研究者角色、`family_links` | 试点前配置研究者账号轮换和停用流程 |
| 内容继续 | 课程与项目资源包 | `content/courses.json`、`programs.json`、训练卡 | 为亲密关系试点增加经人工审核的资源包 |
| 打卡营 | 项目任务、训练卡打卡、每周补充测量 | `checkins`、program entries、relationship tasks/longitudinal | 增加站内日历式提醒，不依赖外部推送 |
| 报告与消息 | 初筛报告、成长报告、站内消息 | `messages`、weekly reports、relationship reports | 报告确认后发送；消息只携带摘要和报告ID |
| 搜索与推荐 | 量表搜索、画像和任务推荐 | assessment search、training maps、profile models | 只按已审核标签推荐，不上传查询原文到第三方 |
| 奖励 | 连续记录、轻量进度反馈 | profile stats、streak、checkins | 使用“记录积累”而非积分排名，避免压力和比较 |
| 人工支持 | 督导、研究者仪表盘与备注 | supervision、researcher dashboard、audit logs | 补充账号审计和待办状态，不建外部群聊 |
| 社群 | 暂不实现 | 无 | 试点验证确有价值后再做匿名、强审核的主题讨论；MVP不需要 |
| 隐私 | 站内权限、脱敏导出、审计 | bearer角色、X-Admin-Token、audit logs、risk review | 敏感原文默认不导出，绘画/句子仅授权研究者可见 |

## 当前站内闭环

```text
账号登录
  -> 关系测一测与阶段性画像
  -> 第二阶段授权报名
  -> 初筛报告与评估问题
  -> 绘画/句子补全/每周补充测量
  -> 研究者复核、备注和报告消息
  -> 成长时间轴与下一步项目任务
```

## 后续升级顺序

1. P0：真机权限和数据隔离验收；研究者账号生命周期；报告下载可用性。
2. P1：站内提醒计划、资源包搜索、任务完成状态和研究者待办。
3. P2：经伦理审查后的匿名同伴内容浏览；默认关闭互动和私信。
4. 暂缓：知识星球深度同步、外部账号自动绑定、敏感数据外传、外部社群自动拉群。

本方案以站内最小闭环为主，不把外部平台当成关键依赖；任何未来同步都必须另做授权、最小字段、撤回和审计设计。

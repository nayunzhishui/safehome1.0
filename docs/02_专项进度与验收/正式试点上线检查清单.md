# 正式试点上线检查清单

创建日期：2026-06-06

项目：`safehome1.0 / 安心陪伴 / ReadFeedback / 安心家平台`

本文档用于正式试点上线前的逐项检查。不包含真实 token、密码或密钥。

---

## 1. 环境变量检查

| 检查项 | 要求 | 验证命令 |
|--------|------|----------|
| `APP_ENV` | `production` | 检查 CloudBase 控制台 |
| `DB_PROVIDER` | `mysql` | `/healthz/deep` 须显示 `provider=mysql` |
| `ALLOW_PRODUCTION_SQLITE` | 未设置或 `0`（仅本地演示可设 `1`） | 检查 CloudBase 控制台 |
| `ADMIN_EXPORT_TOKEN` | 已设置且不是 `safehome-local-admin-token` | 尝试用旧 token 访问应返回 401 |
| `SECRET_KEY` | 已设置，不能是 `safehome-local-dev-secret`，长度不少于 32 字符 | 检查 CloudBase 控制台 |
| `ALLOWED_ORIGINS` | 包含实际访问域名 | 检查 CloudBase 控制台 |
| `MYSQL_HOST`/`MYSQL_PORT`/`MYSQL_USER`/`MYSQL_PASSWORD`/`MYSQL_DATABASE` | 已设置，可连通 | CloudBase 控制台 |

## 7. 伦理与文案抽查

## 9. 回滚策略

如上线后出现严重问题：

```text
1. CloudBase 控制台回滚到上一版本。
2. 数据库保留，不自动删除。
3. 通知项目负责人和研究者暂停新数据写入。
4. 从备份恢复（如需要）。
```

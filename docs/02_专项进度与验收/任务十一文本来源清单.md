# 任务十一文本来源清单

更新时间：2026-07-06

## 1. 使用原则

本清单对应任务十一 T11-15 至 T11-20。文本分析只做离线、脱敏、聚合研究摘要，不输出原始自由文本，不做诊断、筛查、危机预测、人格判断或个体标签。普通用户端不展示复杂社会网络图。

## 2. 代码对齐来源

本表与 `analysis/text_analysis/analyze_text_sources.py` 中 `TEXT_SOURCES` 字段逐项对齐。

| 数据表 | 字段 | 文本类型 | 是否敏感 | 是否默认导出 | 是否脱敏 | 可用于情感计算 | 可用于SNA | 说明 |
|---|---|---|---|---|---|---|---|---|
| `emotion_diaries` | `event_description` | 用户填写 | 是 | 否 | 是 | 是 | 是 | 亲子互动事件描述，只输出场景、情绪、行为等聚合线索。 |
| `emotion_diaries` | `automatic_thought` | 用户填写 | 是 | 否 | 是 | 是 | 是 | 自动想法文本，仅用于聚合情绪和想法线索。 |
| `emotion_diaries` | `behavior` | 用户填写 | 是 | 否 | 是 | 是 | 是 | 行为反应文本，仅用于互动行为节点聚合。 |
| `emotion_diaries` | `raw_text` | 用户填写 | 是 | 否 | 是 | 是 | 是 | 原始记录文本只在本地脚本内读取，不写入输出。 |
| `feedback_results` | `supportive_feedback` | 系统生成 | 否 | 是 | 是 | 是 | 否 | 用于检查系统反馈语气，不用于用户关系网络。 |
| `supervision_requests` | `message` | 用户填写 | 是 | 否 | 是 | 是 | 否 | 人工督导请求敏感度较高，只做聚合，不导出原文。 |
| `supervision_requests` | `reply` | 督导回复 | 是 | 否 | 是 | 是 | 否 | 用于督导质控聚合，不用于用户画像判断。 |
| `checkins` | `reflection` | 用户填写 | 是 | 否 | 是 | 是 | 否 | 训练后反思，用于练习后情绪变化聚合线索。 |
| `emotion_thermometer` | `brief_text` | 用户填写 | 是 | 否 | 是 | 是 | 是 | 简短事件记录，可与温度计强度和反射弧节点聚合。 |

## 3. 输出文件

```text
outputs/text_analysis/text_analysis_summary.json
outputs/text_analysis/text_features_summary.json
outputs/text_analysis/social_network_summary.json
```

输出只允许包含：

```text
1. 来源计数和文本类型计数；
2. jieba 分词后的词典命中聚合；
3. 情绪类别、valence、arousal、强度聚合；
4. 节点、边、中心性、社区和反射弧链条聚合；
5. boundary_notice；
6. raw_text_included=false。
```

## 4. 接入门槛

`/api/text-analysis/summary` 只读取上述离线输出，并要求管理员或研究者鉴权。若离线输出不存在，接口返回 `available=false`，不得临时读取数据库原文补结果。

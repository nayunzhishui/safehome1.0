# 任务十二聚类解释交叉验证报告

更新时间：2026-07-10

## 校验来源与边界

- 聚类输入：`全部数据1.0.xlsx` 中425份可映射的三组题项矩阵；三份量表分别建模，未跨量表合并。
- 解释参照：`数据分析最终整理稿_N469.docx` 与469份清洗维度数据。
- 两个样本口径不同，因此本报告只检查方向和叙事边界，不把聚类当成原分析的复现，也不把相关、回归或中介结果改写成因果或疗效结论。

## 已有分析的可核对事实

1. 主要量表内部一致性达到可接受水平；1a-5b整体α为0.562，不宜合成单一反映式态度总分。乘积信念指标不以α作为主要质量判断。因此模型保留获益、拒绝威胁、真实性威胁和真实性保护的分开解释。
2. 促进聚焦与获益预期、PBC、BI、RAP总体呈正向关系；预防聚焦与图式、威胁预期呈正向关系，但与RAP的相关不显著。因此调节聚焦画像只描述关注方式，不预测实际行动。
3. 早期图式总体与威胁预期正向，与真实性保护、PBC、BI、RAP负向；具体图式与BI、RAP的直接相关较弱。因此Micro YSQ画像只作为担心线索，不写成行动不足的直接原因。
4. BE、SN、PBC共同解释BI变异的47.5%；BI、PBC共同解释RAP变异的32.0%。这支持在关系主动性画像中并列展示获益、支持感、可控感、意愿和行动，但剩余变异仍很大，不能作个体预测承诺。
5. 显著的探索性中介路径包括“促进聚焦→获益预期→BI”和“早期图式→PBC→BI→RAP”。两个调节模型交互项不显著，不应进入画像主叙事。
6. 威胁预期对BI的直接预测不显著，真实性保护单独预测BI也不显著；“风险敏感”不能被自动解释为“不愿行动”。

## 分量表画像方向检查

### 调节聚焦18题

GMM最终保留3个候选簇：成长目标相对突出、成长与安全关注相对平衡、安全顾虑相对突出。PF、PrF和RFD方向与冻结公式一致。画像名称只描述相对关注方向，不使用“积极/消极人格”或关系能力高低评价。

结论：方向可解释；画像数量、名称仍待研究者复核。产品量尺1-7与训练数据1-5的差异已通过模型元数据线性换算，但该处理仍需量表负责人确认。

### Micro YSQ-18

GMM保留4个候选簇，按EMS_M从相对较少到较多形成连续层级。既有分析支持图式线索与威胁、PBC等变量有关，但不支持把单题Micro YSQ直接当成18个稳定图式诊断。

结论：只显示“担心线索较少/浮现/值得梳理”等阶段性名称；不得显示“高图式人格”或病理标签。相邻两个偏低簇的产品可读性有限，人工验收时可考虑合并为3簇。

### 关系主动性：想法、意愿与行动

GMM保留2个候选簇。一个簇的PBC、BI、RAP和获益信念相对较低，另一个簇相对较高；该方向与既有相关和回归结果一致。威胁维度在两簇间差异较小，符合“威胁不必然抑制行动”的已有结果。

结论：使用“仍在观察”与“行动探索相对活跃”的阶段性表述；不能写成“有/无关系能力”，也不能把簇差异写成干预效果。

## 冲突与降级项

- 425份题项矩阵与469份清洗分析样本不是同一口径：所有一致性结论均标记为探索性。
- 调节聚焦新问卷1-7、既往数据1-5：虽已实现显式换算，正式试点前仍需人工确认。
- 清洗表PBC使用4题，而任务十二冻结公式和题项矩阵使用6题：报告和画像均明确当前使用6题，不与旧PBC值宣称完全等价。
- GMM选择依据是BIC、silhouette、最小簇比例、稳定性和可读性门槛的组合；算法不能替代画像数量与命名的人工判断。

最终边界：三份模型用于群体参照、支持性解释、访谈问题和任务推荐，不构成诊断、人格分类、关系能力评价、因果推断或疗效证明。

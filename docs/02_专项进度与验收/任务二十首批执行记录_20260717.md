# 任务二十首批执行记录

日期：2026-07-17

## 1. 关系探索试点如何运作

### 参与者路径

1. 参与者进入“小程序 → 项目试点 → 关系探索试点”。
2. 完成起点支持性测评后，后端保存测评结果和关系试点报名。
3. 参与者在第 2 步查看阶段性报告；报告只作阶段性观察，不构成诊断或关系结论。
4. 参与者继续完成关系绘画、句子补全、项目练习和连续记录。
5. 研究者确认或补充阶段性反馈后，系统生成新报告版本并写入参与者消息列表。
6. 参与者在“我的 → 消息”查看研究者消息，在“关系探索试点 → 成长仪表盘”查看关系试点时间线，在“我的 → 我的成长仪表盘”查看跨模块记录。

### 后端位置

- 关系试点：`backend/routes/relationship_pilot_routes.py` 与 `backend/services/relationship_*`。
- 研究者全模块档案：`backend/routes/research_workspace.py`。
- 站内消息：`backend/routes/messages.py`。
- 人工支持：`backend/routes/supervision.py`。
- 项目逐节填写：`backend/routes/programs.py`。
- 个性化训练节奏：`backend/routes/training_plan.py`。
- 通用成长仪表盘：`backend/routes/general_growth.py`。

### 研究者查看与反馈

- Web：`/dashboard` 的“参与者矩阵与单人全模块档案”。
- 小程序：`pages/researcher-dashboard/index`，用于关系试点轻量处理。
- 研究者只查看分配给自己的参与者；督导/管理员查看全体。
- 原始填写只读；研究者备注、阶段性反馈和消息另存并保留审计。
- 阶段性反馈采用“近期变化—可核对依据—下一小步—待讨论问题”，发送后进入参与者消息列表。

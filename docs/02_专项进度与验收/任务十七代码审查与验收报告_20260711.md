## 2. 已处理发现

1. 候选训练卡曾被跨规则全局截断，导致后续维度卡被通用规则挤出；已改为每条规则最多3张，跨规则不提前丢失，结果页再按项目去重。
2. 课程进度的非数字章节数可能触发500；已改为稳定400 `invalid_completed_section_count`。
3. 项目布尔字段对字符串解析不严格；已统一使用 `parse_bool`。
4. 生产项目提交曾因列表可见性过滤提前变成404，导致明确的未批准阻断不可达；已分离“列表/详情可见”和“提交准入”，生产草案返回稳定409。
5. 重复标签、机器截断三点和用户标题内部缩写已清零，内容校验增加防回归规则。

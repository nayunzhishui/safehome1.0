# 任务二十一训练卡与产品体验专业评审

日期：2026-07-17

## 总体结论

**内容基础扎实，呈现与推送需要整改。** 42 张训练卡已具备低剂量、完成标准、停止规则、适用边界和治理状态；当前主要风险是用户在“选择练习”阶段被迫阅读过多信息，以及推荐逻辑把“完成过”误当成“不应再练”。

## 四个专业视角

### 心理咨询视角

优点：大多数卡聚焦具体场景、可观察动作和复盘，不把一次记录写成诊断；高风险停止规则清楚。

问题：训练卡同时显示大量边界和停止内容，可能让低风险用户产生“这是不是很严重”的额外压力；练习语言偶尔容易被理解为标准答案。

整改：主页面只给一个小目标和一个可选动作；边界保留但不重复；示例明确为参考而不是正确话术；提醒文案不评价坚持、完成率或疗效。

### 产品体验视角

优点：有主练习、备用练习、时长和推荐依据，方向明确。

问题：每张推荐卡在选择前展示目标、情境、节奏、完成、停止、示例、标签、开始前、结束后和边界，三张卡会形成高阅读成本；训练中心同时出现推荐、三日计划、新手路径、阶段路径和完整卡库，入口竞争。

整改：先显示一张“今天练这个”；备用卡压缩为标题、时长和一句用途；详细说明按需展开；卡库默认收起；同一页面只保留一个主按钮。

### 工程设计视角

优点：已过滤需人工语境的卡，高风险阻断普通推荐，测评和日记推荐有规则来源。

问题：通用标签推荐缺少用户语境和近期完成反馈；个性化方案把所有已完成卡永久排除，不符合技能需要重复巩固的特点；缺少系统级提醒的授权、幂等、失败和审计模型。

整改：近期完成采用冷却和降权，不永久删除；没有替代卡时允许重复巩固；订阅消息采用独立偏好/投递表、发送总开关、定时任务令牌和幂等键。

### UI与美术视角

优点：暖白、低饱和绿和圆角体系符合支持性工具的平静感，触控目标总体清楚。

问题：卡片中继续嵌套多层橙、绿、蓝信息块，视觉上每块都像重点；“01/02/03”装饰编号没有帮助用户决定；长页滚动时缺少明确的当前主练习锚点。

整改：绿色用于行动，暖橙只标记当日重点，蓝色保留信息说明；移除无意义编号；主练习增加稳定的标题—时长—目标—按钮结构，详细内容使用统一浅底展开区。

## 认知负荷判断

- 内在负荷：理解自己的场景并选择一个可行练习，必须保留。
- 额外负荷：同时比较三张完整卡、记忆推荐理由、阅读重复边界，应删除或延后。
- 安全摩擦：停止规则、高风险现实支持和订阅授权确认必须保留，但放在正确时机。

## 优先级

1. P0：推荐页渐进披露、一张主练习、备用卡紧凑化。
2. P0：完成卡短期冷却而非永久排除。
3. P0：订阅消息必须主动授权、拒绝不阻断、真实发送默认关闭。
4. P1：训练中心默认收起完整卡库，减少五套入口同时出现。
5. P1：全产品统一错误恢复、状态语言和技术显示名。

## 边界

本评审是产品、内容和工程预审，不替代独立心理、伦理、版权、微信平台审核或真实用户研究。正式试点前仍需由专业人员逐卡签字，并用真实参与者做可用性测试。

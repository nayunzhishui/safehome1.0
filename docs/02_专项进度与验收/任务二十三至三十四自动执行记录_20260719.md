## 2. 用户可见变化

1. 首页保留原有天气、测一测、情绪日记、三步开始、更多、最近记录和阶段反馈，只新增一张动态“今天的一小步”。
2. 即时反馈、消息详情、训练卡和关系阶段报告可选择“符合、部分符合、不符合、让我不舒服”；选择不适不会被解释为风险或诊断，只提示进入人工复核。
3. 隐私中心可看到本人删除申请的处理状态；重复点击不会生成多条待处理申请。
4. 研究者工作台可从汇总数字进入最小处置队列，显示状态、等待时间和必要来源ID，不展示参与者填写原文。

## 5. 与现有功能的冲突记录

1. “唯一主行动”可能被误解为删除首页固定入口；按已冻结决策只增加动态卡，原首页不移动、不折叠。
2. 通用特权代查与参与者本人Journey冲突；只收紧新Journey路由，不改变研究后台既有授权。
3. 既有`helpfulness_rating`和关系报告核对枚举仍有历史用途；新账本兼容读取，不迁移、不删除旧记录。
4. 训练计划已有排序；评价只作为原排序的受控降权输入，不创建第二套推荐算法。
5. 项目草稿目前只在小程序本机；首页仅读取草稿是否存在，不上传草稿原文。
6. 治疗性评估TA-01要求不先建专用表；本轮新增的是全产品通用`feedback_ledger`，未新增TA专用表、页面或真实用户入口。
7. 临时展示越权与T31对象级正式授权目标冲突；按负责人要求保持现状，继续作为正式试点和上线阻断项。
8. 外部治疗性评估原型明确“不保存、不上传、不调用AI”；本轮未把它接入现有数据库/API，避免虚假承诺和未授权数据流。

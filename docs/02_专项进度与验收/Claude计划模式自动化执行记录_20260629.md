## 6. Error Loop 记录

### E1 PowerShell heredoc 语法错误

```text
现象：临时 Python 读取命令误用 Bash heredoc，PowerShell 报 Missing file specification after redirection operator。
原因：当前 shell 是 PowerShell，不支持 `python - <<'PY'`。
修复：改用 PowerShell here-string 管道给 Python。
复测：源文件读取恢复正常。
```

### E2 选项数字被误识别为题号

```text
现象：初版抽取脚本多份量表只抽到 2 题左右。
原因：题目后的 1/2/3/4/5 选项行被当成下一题编号。
修复：纯数字编号后面必须跟非题号题干，且不能跟下一条编号。
复测：严格抽取仅剩真实无编号/短题干问题。
```

### E3 学业浮力第 3 题无题号

```text
现象：学业浮力量表抽取 3/4。
原因：源文件第 3 题题干没有题号。
修复：对该段启用 allow_unnumbered，上一题选项后出现无编号题干时按下一题处理。
复测：学业浮力量表抽取 4/4。
```

### E4 HPLP-C 短题干过滤

```text
现象：HPLP-C 抽取 41/42，漏第 1 题“吃早餐”。
原因：题干长度阈值为 4，短题干被过滤。
修复：题干长度阈值降为 3，同时保留数字选项过滤。
复测：HPLP-C 抽取 42/42。
```

### E5 pytest 依赖缺失

```text
现象：绑定 Python 报 No module named pytest。
原因：Codex bundled Python 未安装 pytest。
修复：使用系统可用 `D:\python\anada\Scripts\pytest.exe`。
复测：目标测试 23 passed。
```

### E6 KMeans Windows/MKL 线程警告

```text
现象：全量聚类初跑时 sklearn 持续输出 KMeans 与 Windows/MKL 线程相关 warning。
原因：Windows + MKL 环境下 KMeans 在线程数较多时会提示潜在内存泄漏风险。
修复：在脚本导入 sklearn 前设置 OMP_NUM_THREADS=1，并降低候选模型 n_init/max_iter。
复测：重新生成 23 个模型时 warning 消失，脚本正常退出。
```

### E7 模型文件名截断导致覆盖

```text
现象：脚本报告 generated_models=23，但 content/profiles 只有 21 个 JSON 文件。
原因：输出文件名用截断后的 model_id，部分长文件名截断后相同。
修复：输出文件名追加 model_id 的 sha1 短哈希，并在全量重建前清理同版本旧模型。
复测：content/profiles 文件数为 23，与生成模型数一致。
```

### E8 画像可视化初版未满足 Canvas 要求

```text
现象：结果页初版用 WXML/CSS 绝对定位绘制散点，未完全满足计划中的 Canvas 2D 散点要求，且缺少雷达图。
原因：接口已返回归一化坐标后，前端先用了轻量 DOM 绘制。
修复：改为 Canvas 2D 绘制群体位置散点；新增题项相对 z 分数雷达图；保留非诊断边界。
复测：结果页 JS 语法检查通过，画像接口测试通过。
```

### E9 小程序视觉清理后残留隐藏插画节点

```text
现象：样式已隐藏插画，但 WXML 中仍有 image 或装饰 view 节点。
原因：第一轮视觉收敛优先处理 CSS，模板资源引用未同步移除。
修复：删除主路径和公共组件里的隐藏插画节点与死样式。
复测：rg 扫描 `linear-gradient|radial-gradient|/assets/illustrations|welcome-art|family-art|tip-plant|hero-image` 无匹配。
```

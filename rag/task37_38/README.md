# 任务三十七至三十八 RAG

本目录用于构建项目内独立、可追溯的检索增强生成链路。

## 分区

- `quarantine/`：网页搜索和新资料的候选隔离区。
- `approved/`：经来源、许可、内容和专业审核后允许索引的清单。
- `indexes/`：可重建索引的元数据，不提交模型缓存或大体积向量文件。
- `evals/`：检索覆盖、引用正确性、拒答和越界测试。

## 准入规则

- 网页搜索结果不得自动进入生产索引。
- 仅允许项目自有、明确授权或审核通过的公开资料进入 `approved/`。
- 原始参与者文本、账号密码、密钥、Cookie、联系方式和可识别隐私不得进入知识库。
- 每个片段必须保留来源、许可/权利状态、版本、哈希、审核状态和适用对象。
- 生成答案必须引用检索证据；证据不足时拒答或提示由真人了解。
- 开发索引与生产索引物理或逻辑隔离，发布需要独立清单、回滚点和审计记录。

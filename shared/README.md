# shared

`shared` 用于小程序端、网页端和后端文档之间统一字段、状态和 mock 数据，避免两端各自定义一套不一致的数据结构。

当前文件：

- `types/api.ts`：MVP 1.0 API 请求、响应和核心数据类型。
- `constants/api.ts`：接口路径、默认用户、状态枚举、常用场景和伦理边界文案。
- `mock-data/mvp.ts`：联调前可用于页面占位和请求结构参考的演示数据。

使用原则：

- 前端页面优先引用这里的类型和常量。
- mock 数据只用于联调前占位，不应替代后端 API。
- 面向家长的文案必须保持非诊断、非标签化、支持性、非评判。

# 首页视觉方向比较

更新时间：2026-08-09

状态：`corrected_concepts_waiting_for_user_selection`

输入基准：`design/context.md` 的“首页需求冻结版 v1”。两种方向原计划保持现有模块顺序和业务入口，不修改前端。

2026-08-09 复核结论：本轮两张 ImageGen 图均淘汰。图片把情绪温度计扩展为天气选择器，替换了“更多”的真实入口，并生成没有后端依据的阶段性反馈结论。以下方向描述只保留为构图研究，不得进入 Figma、代码或视觉验收。

## 方向 A：编辑手帐

组织原则：用文字层级、留白和纸面分区组织首页，让页面像经过编辑的日常陪伴手帐。

- 布局：顶栏简洁留白；情绪温度计为细线横条；测一测与情绪日记为开放式双栏；“今天的一小步”为唯一有明确底色的行动区；其余内容使用分隔线和列表。
- 主行动：“今天的一小步”使用森林绿行动按钮和最大标题层级，但不改变所在顺序。
- 组件：减少卡片外框；“如何开始”改为单行说明；最近记录和阶段性反馈更像摘要条目。
- 品牌母题：极轻纸张纹理、细线和局部叶影，不出现人物。
- 优化：中文阅读、安静感、长期耐看和全站母版复用。
- 牺牲：第一眼的“创意冲击”较克制，需要依靠排版精度体现品质。
- 与目标匹配：强。最能减少模板感，同时适合高压力情境下的阅读。

## 方向 B：连续线索

组织原则：用一条非常轻的纵向细线贯穿固定顺序，让各区块像一天中逐步展开的观察线索。

- 布局：模块顺序不变；细线在各区块之间形成视觉节奏，情绪温度计、双入口、主行动和后续摘要各有不同节点形态。
- 主行动：“今天的一小步”在连续线中形成唯一加宽、加深的节点。
- 组件：开放式区块为主，少量节点标识取代胶囊标签；“如何开始”作为线上的说明入口。
- 品牌母题：细线、纸张纤维和抽象叶脉，不出现人物。
- 优化：页面辨识度和上下滚动的连续感。
- 牺牲：纵向连线可能被理解为必须依次完成，需要弱化编号和完成状态暗示。
- 与目标匹配：中高。创意感更强，但认知歧义风险高于方向 A。

## 推荐

推荐方向 A“编辑手帐”。它最适合不允许调整模块顺序的约束，也更容易让“今天的一小步”成为唯一强视觉行动。方向 B 可作为少量细线节奏的参考，但不采用强流程编号。

## 功能对齐后的重新出图约束

- 只继续探索上述构图语言，不继承淘汰稿中的任何功能内容。
- “情绪温度计”只能表现记录入口和真实摘要，不出现晴、阴、雨等天气选择。
- “支持性反馈”继续进入情绪日记，辅助文案明确“记录后获得反馈”。
- “更多”只保留支持性反馈、训练中心、人工支持三个现有入口。
- “最近记录”表现真实日记摘要和“查看记录”，不跳转或暗示本周复盘。
- “阶段性反馈”只使用真实字段或中性空状态，不编写成长、疗效或人格结论。
- “今天的一小步”只采用后端真实可能返回的标题、描述和按钮示例。
- 模块顺序不变，不增加新功能、新字段、新 API 或后端能力。

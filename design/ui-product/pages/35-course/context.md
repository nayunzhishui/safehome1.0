# UI 冻结：课程

- 方向：方案 A 的安静编辑手帐感，重点是“像翻阅练习目录”，不是营销课程商城。
- 标题：大标题居中，不在大标题下放说明小字；只保留真实页面名称“课程”。
- 信息顺序：本周真实进度 → 主题筛选 → 真实课程卡 → 服务端边界说明。
- 筛选：使用克制的下划线/轻底色状态，不堆积厚重胶囊。
- 课程卡：移除贯穿侧边粗线，改成顶部短书签标记；保留标题、分类、简介、小节数、真实进度和详情入口。
- 文案：删除纯解释性重复小字；必要正文与辅助信息不低于 24rpx。
- 组件：复用 `course-card`、`section-title`、`bottom-tip-card`，同时改善可复用课程卡样式。

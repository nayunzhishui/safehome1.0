# 三步开始页设计上下文

版本：2026-08-11 冻结版

## Goal

让第一次进入的家长在低认知带宽下迅速理解“写一个片段—标一个位置—做一个动作”，并优先进入真实情绪记录页。

## User / JTBD

- 用户：刚开始使用“安心陪伴”、可能正经历亲子压力的家长。
- 核心任务：知道第一步具体写什么，并能立即点击“记录一次”。
- 次要任务：理解情绪反射弧只是观察工具，并可进入训练中心练一个动作。

## Constraints

- 只保留现有 `startDiary` 与 `openTraining` 两个事件。
- 保留 `eventReasons`、`arcNodes`、`exerciseSteps`、`boundaries` 的内容与顺序。
- 不新增接口、保存、进度、勾选、课程、测评、风险分数或诊断能力。
- 页面 JS、后端、API、数据库、content、shared 不修改。
- 可见文字不小于 `24rpx`，正文不小于 `28rpx`；不用小字维持密度。

## Success criteria

- 首屏 3 秒内能识别页面目的与“记录一次”主任务。
- 三步顺序、七段反射弧、三条边界和两个真实路由完整可见。
- 取消卡片墙和双主按钮竞争；主次行动明确。
- Default 与 320px 长内容状态无截断、横向滚动或文字重叠。

## Non-goals

- 不把本页做成可交互教程、进度追踪、训练课程或测评结果页。
- 不解释个体心理、不预测结果、不替代人工支持或专业帮助。

## Frozen direction

采用方案 A“展开的三步练习页”。页面以真实 01–03 顺序为结构签名，数字只表达真实步骤；反射弧使用轻量观察链而非彩色流程图，边界集中一次显示，主行动为“记录一次”。

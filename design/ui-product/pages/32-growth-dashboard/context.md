# 我的成长仪表盘需求冻结

## UIproduct2 冻结（2026-09-08）

四类线索采用2×2紧凑导航，名称与真实数量同排，不把数量放大成成绩。记录与练习的下一步是首个行动面；温度条、同量尺测评、关系事实、研究者反馈各自阅读，不合成总分。时间线复用短竹节节点，不能把导航分类伪造成完成阶段。

正文30rpx、主标题44rpx、元信息26rpx、触控96rpx；保持错误/空态、四栏切换、温度数量映射、hasValue及全部跳转；JS/API不改。关系计数使用开放数据行，取消三张“成绩卡”。保留真实边界信息；Figma全为合成数据且不解释改善。

## 历史冻结


1. 居中标题“我的成长”，标题下不放说明小字；“四类线索不合成总分”移至独立边界条。
2. 顶部分段导航只保留分类名称与真实数量，不显示第三层提示小字。
3. 默认“记录与练习”先展示下一步，再展示温度和时间线；其他三类按原业务切换。
4. 主内容使用开放分区与细分隔线，减少卡片墙；列表用短竹节节点，节点必须贴合真实时间线。
5. 正文不得小于 24rpx；日期等辅助信息允许 24rpx，不加入假趋势、总分或奖励。
6. 保留所有现有操作、空状态、错误状态和边界语义；仅改 WXML/WXSS。

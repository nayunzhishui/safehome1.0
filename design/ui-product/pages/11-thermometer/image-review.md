# 情绪温度计页 ImageGen 审查

## 通过项

- 页面明确保留“情绪温度计”及 1–10 真实强度，不含天气、表情或诊断语义。
- 温度计、点按提示、加减控制、三项补充观察、两个可选输入、记录按钮、回执、曲线、选中点、记录列表与边界均可见。
- 采用开放式连续结构，去掉原来的渐变液柱、高光球体与多层卡片墙。
- 主任务和次级数据层级清楚，正文整体可读。

## Figma 必须纠正

1. ImageGen 的情绪名称计数 `0/20` 与事件计数 `0/30` 不符合代码；改为真实 `0/40` 与 `0/200`，或不显示计数。
2. 回执不能固定为“已记录：强度 5/10”，必须按真实 `receipt.messages` 与 `boundary_notice` 渲染。
3. 曲线次数、平均值、点位和记录均来自真实数据，Figma 仅作 Default 示例，不得写入代码固定值。
4. 补充观察继续使用原生 slider，不增加“低/高、平静/激活、失控/可控”等新数据字段；这些端点文字不进入实现。
5. 补齐真实 Empty、Error、Saving、Receipt 与 SelectedPoint 状态；Loading 不伪造进度数据。
6. 底部边界使用真实 `boundaryNotice`，不替换为概念图新增句子。

采用整体视觉方向，以功能真值表和真实 JS/WXML 字段纠正概念图偏差后复现。

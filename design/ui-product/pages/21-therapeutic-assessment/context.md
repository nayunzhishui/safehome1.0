## 历史冻结

- 页面目标：让用户先进入或继续一次支持性协作，再按需了解治理边界。
- 唯一主任务：继续已有协作；没有协作时开始一次协作。
- 次要任务：直接提交一个协作问题、确认成人首发范围、查看当前协作、记录下一小步。
- 信息顺序：页头 → 当前协作入口 → 提交问题/当前状态 → 下一小步 → 开始前了解 → 资料与共享 → 非诊断边界。
- 风格：方案 A“编辑手账”，自然纸面、开放分隔、墨绿文字、克制橙色主行动。
- 组件复用：只复用适配的 Button 与 PageState；不把五类政策做成组件卡片。
- 小字：可见文案不小于 24rpx；正文默认 27–28rpx；每个辅助区最多两段说明。
- 禁止：诊断、疗效、风险评分、AI 自动判断、虚构顾问/机构、公开方法模板、删除撤回/异议/授权边界。
- 工程边界：只改 WXML/WXSS/必要页面标题，不改 JS、API、数据库、权限、幂等或状态语义。

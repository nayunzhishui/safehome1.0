# 紧急帮助说明页 ImageGen 审查

采用稿：`assets/imagegen-default-v1.png`

结论：`pass_with_figma_adjustments`

生成方式：内置 ImageGen，`ui-mockup` 高保真移动页面概念。

## 功能真值检查

- 通过：四类资源标题、正文与顺序全部保留，页面仍是静态现实支持方向说明。
- 通过：只有底部“查看紧急安全指引”呈现可操作外观；四个资源行没有箭头、按钮、卡片或点击暗示。
- 通过：没有虚构热线号码、拨号、地图、定位、机构搜索、联系人、聊天、在线状态、复制、外链、风险评分、诊断或自动转介。
- 通过：能力边界原文保留，未把本页包装成实时危机服务。

## 视觉检查

- 通过：开放式标题、连续资源索引和细分隔线替代卡片墙，阅读顺序清楚，AI 模板感明显降低。
- 通过：森林绿短竖线形成页面识别特征，但没有编号、箭头或流程语义。
- 通过：危险色只用于“使用边界”标题，未形成高压警示面板。
- 通过：轮廓按钮符合“返回上游安全指引”的辅助操作权重。
- 通过：无插画、图标、照片、渐变、光斑和装饰性伪功能。

## Figma 必须修正

1. ImageGen 画面比例高于 390×844；Figma 需建立 390px 宽可滚动画板，并另做 320px 小屏/长内容状态，不压缩正文。
2. 标题不要机械复刻概念图的超大字号；以项目 32/40 左右的主标题 token 为基线，确保首屏能露出至少两个资源方向。
3. ImageGen 的四个绿色粗竖条不直接复刻。根据用户视觉复核，Figma 改为标题左侧 2px 开放 `┌` 形短角标，不贯穿正文；不添加图标、序号或连接箭头。
4. 正文统一采用项目中文无衬线字体和至少 28rpx 的可读字号，不能照搬图中可能偏小的细字。
5. 轮廓按钮复用本地 `Button / Outline / Default`，保持至少 88rpx 点击高度和真实微信安全区留白。
6. 只实现 Default、LongContent/SmallScreen、Pressed、ReducedMotion；不得伪造 Loading、Empty、Error、NetworkFailure、Disabled 或 Selected。

## 最终生成提示要点

高保真微信小程序内容屏，方案 A“现实支持索引”；开放标题、四个非交互资源行、安静能力边界、底部森林绿轮廓按钮；严格保留全部原文和顺序；禁止热线、拨号、地图、联系人、聊天、风险评分、诊断、转介及任何新增功能。

## 进入 Figma 的条件

采用当前方案。Figma 以功能真值表和冻结文档为最高约束，ImageGen 只定义视觉方向；不得把静态资源说明改造成服务入口。

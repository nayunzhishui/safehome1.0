# 紧急帮助说明页需求冻结

版本：`v1`

日期：`2026-08-11`

路由：`pages/emergency-resources/index`

冻结结论：用户已确认全部页面按方案 A 自动逐页执行；本页采用“现实支持索引”，不再等待额外视觉方向选择。

## Goal

让注意力有限、正在寻找现实帮助的用户快速看懂四类可联系对象，并明确本页只提供方向说明，不提供热线、联络或危机判断。

## User / Scene

- 核心用户：正在为自己或孩子寻找安全支持的家长、学生或其他参与者。
- 使用情境：用户可能从紧急安全指引或“我的”页进入，希望知道现实中可以先找谁。
- 技术场景：微信小程序窄屏阅读；真机、大字体和读屏在全部页面本地完成后统一验收。

## JTBD 与唯一主任务

主任务：扫读并识别适合当前情境的现实支持渠道。

页面唯一控件：`查看紧急安全指引` → `pages/emergency-guide/index`。该控件是返回安全行动页的辅助入口，不伪装成直接联络服务。

## 信息优先级

1. 本页不提供热线或危机判断的关键结论；
2. 四类现实支持渠道及原文说明；
3. 工具能力边界；
4. 返回紧急安全指引。

## 保留

- `resources` 四项标题、正文、顺序与本地绑定；
- `goGuide` 事件和 `navigateTo('/pages/emergency-guide/index')`；
- “不提供热线号码库、不判断危机”的说明；
- 非诊断、非法律判断、非实时危机服务边界；
- 88rpx 最小触控区与 reduced-motion 降级。

## 修改

- 删除 hero 卡、四张重复资源卡和红色警示卡，改为开放式支持索引；
- 用细线、留白和标题层级表达四类渠道，不把静态条目画成按钮；资源标记采用不贯穿正文的 2px 开放角标，禁止重复粗竖条；
- 将返回安全指引降为绿色轮廓辅助行动，避免制造“本页可以直接联系”的错觉；
- 辅助文字不低于 24rpx，正文以 28rpx 为基准。

## 禁止修改

- 不新增热线号码、拨号、地图、定位、机构搜索、联系人、在线状态、聊天、复制、外链、风险评分或自动转介；
- 不修改 JS、数组、路由、API、后端、数据库、content、shared、认证或权限；
- 不把四类静态说明做成可点击资源卡；
- 不使用人物插画、emoji、库存照片、渐变、光斑或循环动效。

## Visual / Motion

- 温暖象牙白背景、深墨正文、森林绿开放角标；危险色只用于能力边界的小标题，不制造警报面板。
- 版式参考清晰的服务索引和联络路径说明，不做医疗机构列表或营销落地页。
- 只有按钮按压反馈，约 120ms；reduced motion 时取消缩放；无入场和循环动效。

## 状态矩阵

- Default：完整四类资源说明与返回安全指引；
- LongContent / SmallScreen：正文自然增高，无截断或横向滚动；
- Pressed：返回按钮按压反馈；
- ReducedMotion：无缩放；
- Loading、Empty、Error、NetworkFailure、Disabled、Selected：不适用，禁止伪造。

## Success / QA

- 约 2 秒内理解“本页只说明现实支持方向”；
- 四类资源可连续扫读，不被卡片容器割裂；
- 所有资源行视觉上明确是说明文字而非可点击操作；
- 页面边界、数组、事件和路由与当前代码一致。

## Evidence / Assumptions / Risks

- 页面代码、上游入口、下游路由和全局 token 已核对；页面无 API 和数据状态。
- 2026-08-09 录屏原文件当前未重新读取，本页无新真机截图；缺口登记到最终真机批次。
- 风险：连接线可能被误解为流程顺序；设计必须弱化步骤感，不使用 01—04 和箭头。

## Rollback

回滚本页 WXML/WXSS/JSON 与对应设计状态即可；页面 JS、数据和后端不变。

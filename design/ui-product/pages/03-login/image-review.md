# 登录页 ImageGen 审查

日期：2026-08-10  
采用稿：`assets/imagegen-default-v2.png`

## 审查过程

- v1 的开放式层级、快捷登录主次和账号兜底方向正确。
- v1 擅自增加“安心陪伴重视你的隐私与数据安全”说明卡和盾牌图标，代码中无此文案与资产，判定不通过。
- v2 已只删除越界说明卡与微信图标，未增加功能，保留原有手机号隐私原文与三种登录路径。

## 通过项

- 功能顺序与真值一致：微信、手机号、账号密码、注册；
- 无忘记密码、验证码、游客、自动注册或其他虚构入口；
- 外层大卡片已移除，依靠标题、留白和细分隔建立层级；
- 深绿只承担首选快捷登录和账号提交，陶土橙仅为隐私脚注的小型提示点；
- 无插画、渐变、光斑、库存人物、嵌套卡片或装饰性图标；
- 输入与按钮尺寸可在 Figma 中按 44px 触控目标复现。

## Figma 修正规则

- 概念稿使用衬线感标题仅作氛围参考；Figma 继续使用已批准的 `Noto Sans SC`，避免生成式字体错位；
- 手机号隐私说明不额外增加橙色项目符号时，也必须保持原文和可读性；
- 普通状态不显示能力提示；只在 API 返回不可用时显示现有 `capabilityMessage`；
- 必须额外建立 Loading、Unavailable、Error、LongContent 与 MustChangePassword 状态。

## 结论

v2 通过功能语义与视觉方向审查，可以进入 Figma 组件化复现。

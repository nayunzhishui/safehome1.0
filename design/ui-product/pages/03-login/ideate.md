# 登录页视觉方向

日期：2026-08-10

## A：编辑式通行页（采用）

- 结构：小型 `SafeHome` 眉题 → “登录”与一句说明 → 快捷登录区 → 隐私/能力提示 → 细分隔 → 账号密码 → 注册文字动作。
- 视觉：暖象牙白画布、森林绿主行动、陶土橙仅用于能力提示细线；不使用插画、渐变和悬浮大卡片。
- 优化：首次进入时能快速找到当前可用方式，同时保留可靠兜底。
- 取舍：不像营销登录页那样强烈，但更符合支持性工具的可信与克制。

## B：账号表单优先（不采用）

- 结构：用户名密码置顶，微信和手机号放在下方。
- 优化：适合已有固定账号的内部人员。
- 取舍：弱化小程序环境中的快捷登录，增加家长和学生输入成本。

## 选择结论

采用 A。它延续首页方案 A 的开放式编辑语言，并严格表现现有三个登录通道、能力不可用、错误/加载和首次改密状态，不增加任何认证能力。

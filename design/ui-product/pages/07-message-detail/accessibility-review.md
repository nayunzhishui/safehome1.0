# 消息详情页无障碍复核

**结论：本地可访问性基础通过，真机读屏与大字体留待最终统一验收。**

## 可在设计与代码中确认

1. 页面有明确的“消息详情”主区域语义，标题、来源时间、正文、核对、边界和返回操作的阅读顺序一致。
2. 来源操作和返回操作均为有文字的按钮；评价项有可访问名称与 `aria-pressed` 状态，不依赖图标或颜色猜测用途。
3. 评价项与页面按钮的最小高度均为 88rpx；四项评价允许换行，窄屏不要求横向滚动。
4. “让我不舒服”除颜色外还有选中按钮文字、结果说明与实时状态文本；撤回状态也使用明确文字，不只依赖视觉样式。
5. 加载、错误、保存结果均有文字反馈；结果提示使用 `role="status"` 与 `aria-live="polite"`。
6. 正文支持换行与任意长词断行，页面保留底部安全区并允许纵向滚动。
7. 页面使用的正文、辅助文字和按钮文字不低于 24rpx；本轮已将 editorial 评价结果提示由 22rpx / Figma 11px 同步修正为 24rpx / 12px。

## 仍需最终真机验证

- 微信读屏下标题层级、评价组选中状态与异步保存状态的实际播报。
- 系统大字体下四个评价项的换行、长正文滚动和底部按钮可见性。
- Android / iOS 的焦点顺序、焦点可见性与弱网错误恢复。

以上项目按当前 Loop 规则统一延期，不登记为已通过。

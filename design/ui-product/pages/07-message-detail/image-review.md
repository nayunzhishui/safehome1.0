# 消息详情页 ImageGen 审查

采用稿：`assets/imagegen-default-v1.png`
结论：`pass_with_figma_adjustments`

## 功能真值检查

- 通过：只展示真实消息类型、标题、来源/时间/版本、正文、条件性报告入口、四项共同核对、边界和返回。
- 通过：没有新增回复、聊天输入、删除、转发、收藏、客服、诊断结论或假数据图表。
- 通过：单一实心主行动为“查看关系探索报告”；反馈选项和返回均为次级控件。
- 通过：文案保持支持性、保守和非诊断，没有把研究者补充写成确定结论。

## 视觉检查

- 通过：采用开放编辑式结构，正文成为视觉中心；没有卡片套卡片、人物插画或通用 AI 聊天气泡。
- 通过：象牙白、森林绿、墨色与灰色关系符合当前 token；中文排版有清楚的标题、元信息、正文与边界层级。
- 通过：所有长文自然换行，四个反馈选项保留足够触控高度。

## Figma 必须修正

1. 概念图标题偏大；Figma 固定为 28/36，避免在 390px 画板中占据过多首屏。
2. 概念图主按钮有轻微明暗变化；Figma 必须使用纯色 `Primary #4F7C6B`，禁止渐变。
3. 概念图纵向内容略超一屏；Figma 以真实滚动页面表达，不压缩边界正文或反馈选项。
4. 增补 MissingId、LoadError、Withdrawn、EvaluationSaving、Evaluated、Uncomfortable、LongContent 等状态，不能只复现默认稿。
5. 元信息允许真实 ISO 时间与版本长文本自然换行，不为效果图硬编码截断。

## 进入 Figma 的条件

采用 A1“编辑式来函”。Figma 复现必须以功能真值表和上述调整为准；ImageGen 只决定视觉方向，不覆盖真实组件、状态或接口内容。

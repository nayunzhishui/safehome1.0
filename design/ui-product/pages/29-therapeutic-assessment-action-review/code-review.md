# 一个小行动页代码复现审查

## 实现范围

- 将共享 `mode="action"` 表单按“想做什么、怎样安排、何时停下”分成三段。
- 日期与提醒使用双列紧凑布局；四个文本域继续使用原 `textarea`、原长度限制、原值与原事件。
- 分组之间使用短线与双竹节；未增加图片、图标、字符计数或解释脚注。

未修改页面 JS、共享组件 JS、participant flow、API、字段、默认值、校验、草稿、版本、幂等、安全门禁或路由。

## 小字门禁

- 保留：可选日期、输入占位、提醒当前值、动态保存状态、自愿确认和错误恢复说明。
- 未新增：行动益处、完成目标、疗效承诺、机器字段、字符计数、版本号、ISO 时间或重复免责声明。
- 可停止与“完成次数不代表疗效”只在页头出现一次。

## Loop 1–4

1. 视觉：ImageGen 的三段便笺、Figma 短竹节分隔和共享 action 结构一致。
2. UI：字段标签、输入正文和分段标题层级清晰；日期与提醒不挤压连续正文。
3. UX：填写顺序符合行动思考过程；自愿确认仍是提交门禁。
4. 状态：空表单、草稿恢复、已确认、校验错误、读取、无已发送反馈、保存、离线和安全暂停完整。

## Harness

- 组件：四个短文本域复用同一紧凑样式，日期与提醒不重复制造组件。
- 业务：六类输入、默认停止/回看内容、确认布尔值和行动回看跳转完整。
- 工程：只修改共享 UI 模板与样式，不触碰后端、数据库、API、content、shared 或业务 JS。

结论：Preview 与全量 Harness 已通过，本页本地完成；真机统一验收延期。

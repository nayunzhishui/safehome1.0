# 资料与共享页审查

## 功能定位

八步协作流程第 5 步。用户决定本轮协作共享范围；账号关联不代表自动互看，范围之后仍可逐条修改或撤回。

## 功能真值

- 共享步骤 `sharing`，模式 `choice`，必须选择后继续。
- 三个真实选项：只共享议题；共享议题和最近事件；暂不扩大共享。
- `question_and_event` 更新为 `question + recent_record`；其余两项保持最小 `question` 范围。
- 保存时复用 scope 更新接口、expected version 与既有幂等键。
- 保留五个组件事件、十个接口、草稿、离线、错误、并发版本、安全暂停、撤回与路由。

## 设计边界

- 页面核心是三选一，不是权限协议或账号说明中心。
- 三条真实选项必须完整保留；不增加“公开/私密”等不存在的级别，不展示 scope 数组、版本号或接口字段。
- 复用 `TherapeuticChoiceOption`、Button、PageState；只保留动态状态，不重复固定边界或增加解释小字。
- 不修改 JS、API 或共享范围语义。

# 开始前了解页需求冻结

- 页面目标：让用户在不被催促的情况下决定是否开始。
- 唯一主任务：选择“我已了解，继续”或“现在先不开始”。
- 布局：轻量步骤标识 → 标题与说明 → 单一选择区 → 上一步/按选择继续 → 边界。
- 风格：方案 A 编辑手账；开放工作纸、细分隔、纸色背景、无浮层卡片。
- 组件：在 Figma 建立一个可复用 `TherapeuticFlowStep/Choice`，代码继续复用已有 `therapeutic-flow-step`。
- 小字：正文 27–28rpx，辅助文案与边界不小于 24rpx。
- 禁止：诊断语气、考试感、倒计时、风险分、自动推荐、强迫继续、额外确认弹窗。
- 工程：只改共享组件 WXML/WXSS 中的视觉呈现；不改 JS、API、字段、路由或业务语义。

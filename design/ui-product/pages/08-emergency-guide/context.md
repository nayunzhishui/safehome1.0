# 紧急安全指引页需求冻结

版本：`v1`

日期：`2026-08-11`

路由：`pages/emergency-guide/index`

冻结结论：用户已确认全部页面按方案 A 自动逐页执行；本页采用“温润编辑感下的安全行动清单”，不再等待额外视觉方向选择。

## Goal

让处在潜在安全风险情境中的家长或学生，第一眼理解“现实帮助优先”，快速读到四项当下行动，并始终容易进入现有现实支持资源页。

## User / Scene

- 核心用户：正在为自己或孩子寻找安全支持的家长、学生或其他参与者。
- 使用情境：可能紧张、注意力有限、阅读耐心下降；页面必须直接、克制，不要求用户理解内部风险级别。
- 技术场景：微信小程序窄屏、单手操作；真机读屏和大字体在全部页面本地完成后统一验收。

## JTBD 与唯一主任务

主任务：先找到现实帮助。

唯一实心主行动：`查看现实支持资源` → `pages/emergency-resources/index`。

次行动：`回到首页` → `wx.reLaunch('/pages/home/index')`。

## 信息优先级

1. 安全优先与现实帮助结论；
2. 四项“现在先做”；
3. 现实支持资源主行动；
4. 5-4-3-2-1 接地法；
5. 小程序能力边界；
6. 回到首页。

## 保留

- `supportSteps`、`groundingSteps` 的真实顺序与原文；
- `openResources` 与 `goHome` 事件；
- `navigateTo` 与 `reLaunch` 的真实路由语义；
- 非实时、非诊断、非法律判断边界；
- 88rpx 最小触控区与 reduced-motion 降级。

## 修改

- 删除 hero、九个步骤卡和风险卡堆叠，改用标题、编号、分隔线与留白建立层级；
- 四项现实行动使用 01—04，接地法使用真实 5—1 大数字，解决当前视觉编号冲突；
- 将现实资源主行动放入固定底部安全行动区，长内容滚动时仍可达；
- 将返回首页降为文字明确的低强调按钮；
- 辅助文字不低于 24rpx，正文以 28rpx 为基准。

## 禁止修改

- 不新增拨号、定位、报警、热线号码、聊天、自动转介、风险检测、诊断或专业人员在线状态；
- 不修改页面 JS、API、后端、数据库、content、shared、认证或权限；
- 不用红色制造恐慌，不用绿色暗示问题已经解决；
- 不用人物插画、emoji、库存照片、渐变、光斑或循环动效。

## Visual / Motion

- 温暖象牙白背景、深墨正文、危险色仅用于“安全优先”和关键细线、森林绿仅用于现实资源主行动；
- 版式参考行动清单与编辑式安全说明，不做医疗警报面板；
- 只有按钮按压反馈，约 120ms；reduced motion 时取消缩放；敏感内容无入场和循环动效。

## 状态矩阵

- Default：完整本地内容与固定安全行动区；
- LongContent / SmallScreen：内容纵向滚动，底部预留固定行动区高度；
- Pressed：主次按钮按压反馈；
- ReducedMotion：无缩放；
- Loading、Empty、Error、NetworkFailure、Disabled、Selected：不适用，禁止伪造。

## Success / QA

- 约 2 秒内看懂“现实帮助优先”；
- 不滚动也能找到现实资源主行动；
- 5-4-3-2-1 顺序无歧义；
- 页面只有一个实心主行动，无嵌套卡片；
- 代码事件、数组、路由和文案边界与当前实现一致。

## Evidence / Assumptions / Risks

- 代码、上游入口、下游资源页与全局 token 已核对；页面无 API 和数据状态。
- 2026-08-09 录屏在当前本机原路径已不可用，本页无新的直接截图；该缺口登记到最终真机批次。
- 风险：固定底部行动区可能遮挡长内容；实现必须增加等量底部留白并在不同安全区复核。

## Rollback

回滚本页 WXML/WXSS/JSON 与对应设计状态即可；页面 JS、数据和后端不变。

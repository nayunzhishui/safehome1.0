# 紧急安全指引页方向发散

## 方向 A：安全行动清单（采用）

原则：先现实行动，再辅助稳定。

- 布局：开放标题 → 四项 01—04 现实行动 → 5—1 感官阶梯 → 低强度能力边界；固定底部放现实资源主按钮和低强调首页按钮。
- 组件：SafetyActionRow、GroundingStep、SafetyActionDock；优先复用 Button token。
- 优化：紧张情境下的扫读速度、主行动可达性、现实帮助与接地法的层级区分。
- 牺牲：固定底部占用部分视口，需要为长内容增加安全留白。
- 与目标匹配：最强；直接服务“先找到现实帮助”。

## 方向 B：5→1 稳定阶梯

原则：以大号 5、4、3、2、1 形成单一路径，把四项现实行动压缩为顶部提醒带。

- 布局：安全结论 → 现实帮助提醒带 → 大号 5→1 阶梯 → 底部资源行动。
- 组件：GroundingStep 为主要视觉，现实行动变为紧凑列表。
- 优化：练习记忆性与页面视觉识别。
- 牺牲：容易让用户误以为接地练习可以替代联系现实帮助，不符合本页最重要的安全优先级。
- 与目标匹配：较弱，不采用。

## 方向 C：双路径安全面板

原则：把“联系现实支持”和“稳定当下”并列为两个区块。

- 布局：结论 → 两个并列行动区 → 边界 → 双按钮。
- 组件：两个同权重面板。
- 优化：内容分类明显。
- 牺牲：在手机上形成双主任务和更多卡片，增加判断成本，也削弱现实帮助优先。
- 与目标匹配：不采用。

## 决策

按用户已冻结的方案 A 执行。视觉概念必须表现“现实行动优先、接地法辅助、现实资源持续可达”，不得将危机场景设计成教程卡片墙或练习打卡页。
